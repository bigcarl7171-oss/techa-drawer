# 장면 데이터 문법 — 글자가 연출을 정한다

`scriptdata.py`의 장면 한 칸 = `(화면, 애니메이션, 자막 박스, 낭독, 효과음, 사진)`.
렌더러(`scripts/render.py`의 `analyse`)가 **화면·애니메이션 글자**를 읽어 자동 연출을 붙인다. 원고를 쓸 때 이 표대로 단어를 넣는다.

## 화면·애니메이션 → 연출
| 쓰는 법 | 연출 | 예 |
|---|---|---|
| 화면에 `'70'` 처럼 따옴표 속 2~3자리 숫자 | 큰 숫자 | `달력 위 '70'` |
| 위 + 애니메이션에 `X` | 숫자 위 빨간 X (숫자가 하나일 때만) | `빨간 펜으로 X` |
| 따옴표 숫자 두 개 | 왼쪽 숫자 → 오른쪽 숫자 등장(두 번째는 그 숫자를 **말할 때**) | `'70' 옆에 '69'` |
| `도장`·`팻말` + 따옴표 단어 | 도장 (낭독에 `///`가 있으면 **뜸 뒤 첫 마디**에 찍힘, 자막 박스·효과음도 같은 순간) | `노란 골든로드에 '무죄' 도장` |
| 화면에 `O 팻말` | '진짜 금기' 도장 | `고양이 + 백합에 O 팻말` |
| 화면에 `△` | '나라마다 달라요' 도장 | `국화에 △ 팻말` |
| 화면에 `八十八` / `喜` / `古稀` | 한자 합체 八十八→米, 喜→七十七 / 붓글씨 古稀 (합체는 낭독에서 **'겹쳐'·'흘려'를 말할 때**) | |
| `A vs B` 또는 `A / B` (카드·체크리스트 아님) | 2~3분할 화면 + 라벨 (vs면 VS 배지) — 사진도 `[a, b]` 로 | `생화 vs 프리저브드 나란히` |
| `D+1` | 왼쪽 패널만 날마다 시드는 날짜 카운터 | `'D+1 → D+7' 칩이 넘어가며 왼쪽만 시듦` |
| 애니메이션 `밝기` 또는 화면 `켜짐` | 어두웠다 불이 켜짐 | `밝기 0→100%` |
| 애니메이션 `음악 정지` | 도장 직전 0.6초 BGM 멈춤 | `음악 정지 → 도장` |
| 애니메이션 `타임랩스`·`2배속` | 카메라 이동 1.8배 | |

## 자막 박스 → 칩
| 쓰는 법 | 결과 |
|---|---|
| `제목/가 · 나 · 다` | 위에 자막 박스 '제목', 그 위로 칩 3개 (각 16자 이내, 2~5개) |
| `가 · 나 · 다` (한 줄) | 칩만 |
| `10월 탄생화는?/①국화 ②코스모스 ③금잔화` | 제목 + 번호 칩 |
| 화면·애니메이션·효과음에 `체크` | 칩마다 골드 체크 + 딸깍 |
| 칩은 낭독에서 **그 단어를 말할 때** 하나씩 뜬다 — 칩 글자의 첫 단어(또는 앞 두 글자)가 낭독에 있어야 정확히 맞는다 | |
- `/` 는 자막 박스 줄바꿈. 첫 장면(0번)은 자막 박스 대신 첫 화면 큰 문구(`thumb`)가 뜬다.

## 효과음 칸 → 소리 (`scripts/audio.py`의 `SFX_RULES`, 위에서부터 먼저 맞는 것)
셔터·찰칵 / 계산기 / 도장·쾅 / 유리잔·팅 / 지폐·차르륵 / 물방울·똑 / 바람 / 피아노 저음 / 가위 / 다이얼·전화 /
못에·팻말·놓는 소리 / 그릇 / '후'·초 끄는 / 에어컨·소음 / 펜·긋·연필·붓 / 딸깍·스위치·체크·버튼 /
종이·넘기·카드·편지·서류·파일·포장지·바스락·비닐·상자·봉투·리본·옷걸이·줄기·돋보기·지도·달력.
`+` 로 여러 개, `3번`처럼 횟수. `—` 는 없음. 키워드가 하나도 안 맞으면 소리가 안 나니 원고 검사 스크립트로 확인한다.

## BGM (`plan_data.py`의 `bgm` 글자 → `audio.style_for`, 코드로 합성 = 저작권 걱정 없음)
콘트라베이스·느와르 → noir / 재즈 → jazz / 오르골·글로켄 → bells / 피치카토·우쿨렐레 → quiz / 마림바 → marimba / 기타 → guitar / 그 외 piano.
`첫 4초 무음`이 들어 있으면 첫 4초 음악을 끈다(첫 장면에 내레이션이 있으면 `scriptdata`의 `bgm`으로 덮어써 뺀다).
내레이션 중엔 BGM이 자동으로 줄어든다(덕킹 0.16).
