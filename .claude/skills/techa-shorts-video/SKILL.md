## 사장님 기준 (우선순위대로)
1. **내용이 먼저다.** 기술이 완벽해도 "아무것도 모르는 사람이 봐도 무슨 영상인지, 뭘 알게 되는지, 재미있는지"가 모호하면 실패다. 원고는 `refs/shortform-formula.md` 대로.
2. **원고를 먼저 보여 드리고 확정받은 뒤** 영상을 만든다(렌더 30분 + TTS 비용이 들기 전에). 원고만 출력해 달라고 하면 렌더하지 않는다.
3. 내레이션은 또박또박, 맥락대로 쉬고, 숫자는 한글로 읽는다. 화면·자막·칩·효과음은 말에 맞춘다.
4. 결과는 **버전별 새 폴더**로. ⛔ 덮어쓰지 않는다. 렌더가 실패했으면 내보내지 않는다.
5. 비용이 드는 도구(힉스필드 등)는 쓰지 않는다 — 무료로 되는 방법을 먼저 찾는다.

## 순서
1. **원고 쓰기** (`scriptdata.py`) — `refs/shortform-formula.md` §0의 세 줄(주제·기억할 한 줄·테차 연결)부터.
   근거: `techa-brand-rules.md` §1·§2·§4-3, `D:/claude-practice/script-guide.md` §4·§7, `docs/review-analysis-2026-08.md`(검증된 후기 원문·데이터).
   - 첫 문장 = 누구를 위한 무슨 영상인지. 목차 약속 → 첫째·둘째·셋째 → 개념부터 쉬운 설명 → 재미 하나 → "정리하면" → 테차.
   - 확인 안 된 상품 사실은 원고에 넣기 전에 사장님께 묻는다(아래 '열린 확인 사항').
2. **원고를 사장님께 출력** — 편마다 [자막] + 내레이션, '알려 주는 것'·'재미' 한 줄씩. 피드백 반영 후 확정.
3. **낭독 표시** (`scriptdata.py` 낭독 칸) — `/` 짧은 숨 · `//` 쉼 · `///` 긴 뜸(질문 뒤·반전 직전). 의미가 이어지면 쉼표가 있어도 표시하지 않는다. **쉼 = 자막 줄바꿈**, 한 토막 ≈ 15자. 장면 끝 표시 = 다음 장면 전 쉼(0.45/0.85/1.25초).
   숫자는 `{70세|칠십 세}` `{6칸씩|여섯 칸씩}` `{10월|시월}` `{USB|유에스비}` `{1~3년|일 년에서 삼 년}` — 한자어/고유어 수를 맥락으로.
4. **장면 사진** (사진 칸) — 원본 사진 전체를 이름 붙인 격자로 뽑아 보고 내레이션 내용에 맞는 사진을 직접 고른다. 없으면 다른 편 사진(`03/img-2.jpg`). 피사체가 한쪽이면 `@초점`.
5. **점검**: `python check_script.py` — 연출·효과음 키워드·맨 숫자·사진 파일·예상 길이. 문제 0건이 될 때까지.
6. **내레이션**: `python tts.py [slug…]` (11편 약 3분). 장면을 통째로 합성(억양 유지) + `markup` 쉼 태그 → 오디오에서 무음을 찾아 대본 쉼과 짝지어(`align`) 토막 시각을 `vo/<slug>/NN.json`에. 로그의 `쉼 N / 무음 M`에서 M<N이면 그 쉼은 추정값(남성 Charon은 짧은 숨을 거의 안 쉰다).
7. **렌더링**: `python render.py [slug…]` — 편당 약 3분, 2편 동시 → 11편 약 30분. **렌더 중엔 다른 무거운 작업을 돌리지 않는다**(동시에 돌렸다가 메모리 부족으로 인코더가 죽은 적 있음).
8. **검수**: 로그 exit 0 · 편 수 · mp4 시각 확인 → `NN-slug-qa.json`(세이프존 이탈·겹침 0, `_검사한_글자블록` > 0) → 편마다 프레임 격자로 원고·사진·주제 표시를 눈으로:
   `ffmpeg -i X.mp4 -vf "fps=1/3,drawbox=x=60:y=220:w=890:h=1270:color=red@0.9:t=5,scale=180:-1,tile=17x1" -frames:v 1 grid.jpg`
   반전·도장·한자 장면은 0.3초 간격으로 따로 뽑아 소리·화면 타이밍을 본다. 초점 빗나간 컷(팔만·창문만 보이는 컷)은 `@초점`을 고쳐 그 편만 다시.
9. **내보내기**: `…\클로드작업11편1차\완성_<이름>` 새 폴더에 mp4·썸네일·`원고vN.md`·`업로드카피.md`. 길이(60초 넘는 편)를 함께 보고한다.

## 움직임
- 카메라: 장면마다 밀기·오른쪽 이동·빠지기·왼쪽 이동을 번갈아(사진 초점 중심, 확대 최대 14%). 새 자막 화면마다 0.45초 2.2% 다가감(`beat_pulse`).
- 사진 움직임(`motion.py`, 무료): 거리 지도로 느린 원 궤도 패럴랙스 + 가까운 꽃만 미세하게 흔들림 + 밝은 곳(무드등) 숨쉬기. 얼굴·손·지폐 글자를 새로 그리지 않아 일그러지지 않는다. 거리 지도는 사진마다 한 번 계산해 `work/depth/`에 저장.

## 동기화
- 장면 길이 = 내레이션 + 앞 0.15초 + 대본 끝 쉼.
- 하단 자막 화면은 그 화면 첫 토막을 말할 때 바뀌고 둘째 줄은 그 줄을 말할 때. 칩은 그 단어를 말할 때(`spoken_at`), 칩 효과음도 같은 순간.
- **반전**: `///` + 도장 장면은 도장·위쪽 자막 박스·첫 효과음을 뜸 뒤 첫 마디에(`stamp_t`), 음악 정지는 도장 직전 0.6초. 뜸 동안 답이 먼저 보이면 반전이 죽는다.
- 두 번째 큰 숫자(70→69)는 그 숫자를 말할 때, 한자 합체는 '겹쳐'·'흘려'를 말할 때.
