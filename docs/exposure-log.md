# 노출 결과 기록 — 발행한 글이 실제로 네이버 VIEW에 떴는가

**이 표가 다음 판단의 근거다.** 2026-09-19~20에 SERP를 자동으로 재다가 세 번 연속
검출기가 틀렸다(쇼핑 유무·꽃 상품 수·블록 순서). 텍스트 수집본으로는 화면을 알 수 없다는
것이 결론이었고, 그래서 **추정을 멈추고 실제 노출 결과로 판단하기로 했다** (2026-09-20 결정).

19편쯤 쌓이면 이 표만 보고 답할 수 있다 — 어떤 성격의 키워드가 실제로 뚫렸는가.

## 기록하는 법

발행 3~7일 뒤에 네이버에서 직접 검색해 한 줄 채운다 (`techa-publish` S8).
네이버 블로그에 올린 글 기준이다. techa.kr 매거진은 네이버 VIEW에 안 뜬다.

- **주력**: 그 글이 노린 키워드 하나
- **클러스터**: 해시태그로 같이 노린 키워드 1~2개
- **VIEW 위치**: 화면에서 블로그·카페 영역이 시작되는 지점을 눈대중으로. `상`(첫 화면 안) ·
  `중`(한 번 스크롤) · `하`(두 번 이상). 이게 자동으로 못 쟀던 값이다
- **순위**: VIEW 영역 안에서 테차 글이 몇 번째인지. 안 보이면 `-`
- 안 떴으면 안 떴다고 적는다. **빈칸으로 두면 이 표가 무용지물이 된다**

1. **뚫린 글과 안 뚫린 글의 차이가 무엇이었나** — 키워드 성격? VIEW 위치? 경쟁 구성?
2. **클러스터가 실제로 여러 키워드를 잡았나** — 한 편이 둘 이상에서 보였는가.
   `serp-vertical-strategy-2026-08.md` §3의 solmade4425 가설을 검증하는 유일한 방법이다

4. 그 뒤에 주제 선정 기준을 다시 세운다
