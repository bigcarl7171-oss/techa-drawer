## 읽을 때 주의

- **날짜가 붙은 문서(`-2026-08` 등)는 그 시점의 조사 기록이다.** 결론이 지금도
  맞는지는 따로 확인한다. 특히 검색량·순위·경쟁 지형은 빨리 낡는다.
- 문서끼리 어긋나면 **`techa-brand-rules.md` 와 `AGENTS.md` 가 우선**이다.
  실제로 `blog-seo-guide.md` 가 더 오래된 방침을 담고 있던 전례가 있다.
- 숫자를 인용할 때는 그 숫자가 어떻게 측정됐는지까지 본다. `wc -m` 이 한글을
  바이트로 세어 분량 기준이 3배 부풀려졌던 사고가 있었다
  (`blog-seo-guide.md` §자수 세는 법).
