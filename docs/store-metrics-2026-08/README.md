# 스마트스토어 성과 데이터 — 받는 방법

3개월 개선 작업의 **기준선(baseline)**이다. 이걸 안 남기면 3개월 뒤
"뭐가 효과였는지" 판정이 불가능하다.

> **왜 사장님이 직접 받아야 하나**: 스마트스토어는 봇 차단이 강해
> (직접 요청 429, 프록시 490, 브라우저 정책 차단) 자동 수집이 안 된다.
> 판매자센터 로그인이 필요한 데이터라 로그인 없이는 접근할 수 없다.

---

## 받을 파일 3개

전부 **최근 3개월**(2026-05-14 ~ 2026-08-14) 기준으로 받는다.

### 1. 상품별 성과 → `product-performance.csv`

```
판매자센터 → 통계 → 상품성과
기간: 최근 3개월 → 엑셀 다운로드
```

꼭 포함돼야 하는 열:

| 열 | 왜 필요한가 |
|---|---|
| 상품명 | 21개 페이지 식별 + 상품명 감사의 원본 |
| 상품조회수 | 노출/유입이 되고 있는가 |
| 결제수 | 실제 주문 건수 |
| **결제전환율** | **가장 중요.** 상세페이지 문제인지 유입 문제인지 가름 |
| 결제금액 | 매출 기여도 |

### 2. 유입 검색어 → `search-keywords.csv`

```
판매자센터 → 통계 → 마케팅분석 → 검색채널
기간: 최근 3개월 → 엑셀 다운로드
```

검색어별 **유입수**와 가능하면 **결제수**까지. 이게 상품명 감사의 핵심 재료다 —
실제로 사람들이 뭐라고 검색해서 들어오는지 알아야 상품명에 넣을 키워드가 정해진다.

### 3. 상품별 리뷰·찜 → `product-reviews.csv`

```
판매자센터 → 상품관리 → 상품조회/수정
```

목록에서 **리뷰수 / 평점 / 찜수**가 보이면 그대로 내려받고,
안 되면 화면 캡처만 주셔도 된다(21개라 캡처로도 충분).

| **조회수 적음** | ⚪ 후순위 (정리 검토) | 🟡 상품명·키워드 문제 (노출만 늘리면 바로 매출) |

## 데이터가 없거나 부족하면

판매자센터 통계는 보관 기간이 있다. 3개월치가 안 나오면:

- 있는 기간만이라도 받는다 (1개월치라도 없는 것보다 낫다)
- 그 경우 3개월 후 비교는 **동일 기간 길이**로 맞춘다
- 계절성 보정을 위해 **작년 같은 기간** 데이터도 함께 받아두면 가장 좋다
  (8월→11월은 졸업·연말 성수기로 넘어가는 구간이라 자연 증가분이 섞인다)
