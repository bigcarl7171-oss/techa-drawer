# 색인 요청 절차 (구글·네이버)

CLAUDE.md 에 "구글 색인 요청·네이버 수집 요청은 API 가 없어 자동화 못 한다"고만
적혀 있어 실제 경로가 없었다. 손으로 해야 하는 일이라 순서를 여기 남긴다.

작성 2026-09-08.

---

## 원칙 — 페이지 하나씩 넣지 마라

허브 페이지 하나만 요청하면 크롤러가 거기 걸린 링크를 타고 나머지를 발견한다.
할당량은 아껴서 **새로 만든 허브·목록 페이지**에 쓴다.

| 상황 | 요청할 것 |
|---|---|
| 매거진 새 글 발행 | 그 글 URL 하나 |
| 도구 여러 개 추가 | `/ko/` 하나 (허브가 링크한다) |
| 사이트맵만 갱신 | 아무것도 — 사이트맵 재제출로 충분 |

---

## 구글 — Search Console

https://search.google.com/search-console (속성: `techa.kr`)

### 사이트맵 제출
좌측 **색인생성 → Sitemaps** → "새 사이트맵 추가" 에 `sitemap.xml` 입력 → 제출.

- 도메인 앞부분은 이미 붙어 있어 **파일명만** 넣는다.
- 이미 제출한 것을 다시 넣어도 중복이 안 생긴다. URL 이 많이 늘었을 때 재크롤링을 앞당기는 용도로 쓴다.

⚠️ **일반 페이지 주소를 여기 넣지 마라.** 구글이 XML 로 파싱하려다 HTML 을 만나
"오류 1개 · 발견된 페이지 0" 으로 남는다. 2026-09-08 기준 이렇게 잘못 들어간
줄이 4개 있다(`/`, `/blog/`, 글 2개). 해가 되진 않지만 진짜 오류를 가린다.

목록 화면의 ⋮ 에는 삭제가 없다. **사이트맵 주소를 클릭해 상세 화면으로 들어간 뒤
오른쪽 위 ⋮ → 사이트맵 삭제.** 그래도 안 보이면 방치해도 무방하다.

### 개별 URL 색인 요청
맨 위 **URL 검사** 창에 전체 주소를 넣고 엔터 → **색인 생성 요청**.

- 하루 약 10건. 같은 URL 을 반복 요청해도 순위에 도움이 안 된다.
- "URL이 Google에 등록되어 있지 않음" 은 새 페이지면 정상이다.

### 결과 확인 시점
| 시점 | 볼 것 |
|---|---|
| 1~2일 | Sitemaps 의 "발견된 페이지" 수 |
| 1주 | URL 검사로 해당 페이지 색인 여부 |
| 2~4주 | 색인생성 → 페이지의 "알려진 페이지 / 색인 생성됨" |

## 네이버 — Search Advisor

https://searchadvisor.naver.com

소유확인은 `index.html` 의 `naver-site-verification` 메타태그로 이미 돼 있다.
태그를 지우면 소유확인이 풀리므로 건드리지 말 것.

### 등록 주소부터 확인
**사이트 관리** 목록에 `https://www.techa.kr` 로 등록돼 있어야 한다.
`http://` 나 www 없는 주소로 등록돼 있으면 정식 주소를 새로 등록한다
(기존 것은 지우지 않아도 된다).

### 사이트맵 제출
**사이트 관리 → 사이트 선택 → 요청 → 사이트맵 제출**

```
https://www.techa.kr/sitemap.xml
```

⚠️ 구글과 달리 **전체 주소**를 넣어야 한다. 파일명만 넣으면 안 된다.

### 웹 페이지 수집 요청
**요청 → 웹 페이지 수집**. 하루 50건으로 구글보다 넉넉하다. 한 번에 한 줄씩.

### 간단체크는 제출이 아니다
상단 **간단체크** 탭은 robots.txt·메타태그·제목 등을 진단만 한다. 여기서
전부 ✓ 가 떠도 **아무것도 제출되지 않는다.** 수집 요청은 사이트 관리 탭에서 한다.

### 기대치
네이버는 일반 웹사이트에 인색하다. 블로그·카페·스마트스토어를 상위에 올리고
개인 사이트는 "웹사이트" 탭으로 밀린다. 수집 요청을 다 넣어도 구글만큼의 유입은
기대하기 어렵다. **네이버 유입은 사이트 수집보다 네이버 블로그에 원고를 올리는
쪽이 본선이다** (techa-publish 스킬의 네이버판 원고).

## 자동화할 수 없는 이유

구글 Indexing API 는 채용공고·라이브중계 구조화 데이터에만 열려 있어 일반
페이지에는 못 쓴다. 네이버는 공개 API 자체가 없다. 둘 다 사람이 눌러야 한다.
