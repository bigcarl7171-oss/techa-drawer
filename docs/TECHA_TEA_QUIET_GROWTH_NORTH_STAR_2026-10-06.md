# TECHA Tea 장기 개발 원칙 — Quiet Growth North Star

작성: 2026-10-06  
적용: techa.co.kr / TECHA Tea / 테차티  
성격: 현재 노출 전략과 최초 플랫폼 비전을 함께 지키기 위한 상위 개발 원칙

## 1. 현재 단계의 브랜드 우선순위

당분간 사람과 검색엔진이 단독 이름 **테차 / TECHA**를 접했을 때 가장 먼저 연결해야 할 대상은 **테차 꽃공방**이다.

현재 공개 브랜드 축은 다음처럼 운영한다.

- **테차 / TECHA = 테차 꽃공방**
- **www.techa.kr = 테차 꽃공방 대표 사이트**
- **TECHA Flower = 꽃 사업의 영문 표현**
- **네이버 블로그 ‘테차 꽃공방’ = 꽃 콘텐츠 채널**
- **네이버 플레이스·구글 비즈니스 프로필 = 꽃공방의 지역·업체 정보 채널**
- **스마트스토어 = 꽃 판매 채널**
- **techa.co.kr = TECHA Tea**
- **TECHA Tea / 테차티 = 차 지식·생활문화 플랫폼의 고유 표시명**

검색 결과를 인위적으로 보장할 수는 없지만, 사이트명·구조화 데이터·내부 링크·콘텐츠 표기는 이 방향으로 일관되게 관리한다.

## 2. 노출은 비대칭으로 운영한다

### 꽃공방 → TECHA Tea

꽃 사이트와 블로그에서는 TECHA Tea를 숨기지 않되 크게 전면화하지 않는다.

원칙:
- 푸터·About·관련 글에서 1~2문장 정도 자연스럽게 언급한다.
- 예: “테차는 꽃과 차가 함께하는 생활문화를 오래 이야기하고 있습니다. 차 이야기는 TECHA Tea에서 천천히 쌓아갑니다.”
- 대형 배너, 메인 메뉴 우선 노출, 반복 CTA로 꽃 고객의 목적을 흐리지 않는다.
- 단독 ‘테차/TECHA’ 검색 정체성을 차 사이트와 경쟁시키지 않는다.

### TECHA Tea → 테차 꽃공방

차 사이트에서는 꽃공방을 더 적극적으로 보여도 된다.

원칙:
- 헤더·푸터·About·꽃과 차 콘텐츠에서 **테차 꽃공방**을 명확히 연결한다.
- 차 사이트의 출발 배경이 실제 꽃공방과 같은 TECHA 생활문화에서 왔다는 점을 숨기지 않는다.
- 상품 판매 배너를 남발하지 않고, 꽃공방·공간·선물·계절·환대와 연결되는 문맥에서 소개한다.
- 카피의 정서는 **“꽃과 차가 함께 어울리는 곳”**, **“한 잔과 한 송이가 머무는 생활”**처럼 생활문화 중심으로 잡는다.

이 비대칭은 장기 브랜드의 서열을 뜻하지 않는다. 현재 꽃 사업의 인지도와 검색 자산을 보호하면서 차 사이트가 충분한 내실을 갖출 시간을 확보하기 위한 운영 전략이다.

## 3. TECHA Tea는 조용히 움직인다

TECHA Tea는 지금 크게 알리는 사이트가 아니다.

당분간의 목표:
1. 검색에 필요한 기본 구조를 유지한다.
2. 검증 가능한 차 데이터와 한국어 설명을 계속 축적한다.
3. 읽을 만한 차 이야기와 현장 기록을 늘린다.
4. 차를 실제로 마실 때 쓰는 기능을 하나씩 만든다.
5. 반복 방문할 이유를 만든다.
6. 충분히 쌓인 뒤에 알려간다.

사이트가 아직 얕은 상태에서 광고·과도한 홍보·판매를 앞세우지 않는다.

## 4. 최초의 웅장한 계획을 축소하지 않는다

TECHA Tea의 장기 목표는 단순한 차 백과사전이 아니다.

최초 플랫폼의 핵심 흐름을 계속 유지한다.

**마셔보기 → 궁금해하기 → 알아보기 → 비교해보기 → 기록하기 → 함께하기 → 산지까지 가보기**

또 다른 표현으로는:

**배운다 → 마신다 → 기록한다 → 이야기한다 → 다시 방문한다**

데이터와 정확성은 이 경험을 가능하게 하는 뼈대다. 사이트 전체의 얼굴은 호기심, 사람, 이야기, 여행, 공간, 차생활이어야 한다.

## 5. 장기적으로 만들어야 할 핵심 층

### A. 지식과 데이터
- 차 백과
- 다류·나라·산지·품종·제조·등급·연도 관계
- 출처와 검증 상태
- 한국어 명칭·현지명·별칭
- 다중축 검색과 비교

### B. 이야기와 현장
- 직접 촬영한 산지 사진
- 운영자의 여행·시음·제다 경험
- 생산자·사람·마을
- 전설과 확인 가능한 기록의 구분
- 차의 역사와 문화
- 꽃·책·음악·계절·공간과 연결되는 이야기

### C. 실제 차생활 도구
장기 P0로 계속 유지한다.
- 내 차 기록
- 우림 타이머와 다회 우림
- 지난 우림 조건 재사용
- 관심 차·글 보관
- 두 차 비교
- 이번 주 차 실험
- 기록 내보내기·가져오기

처음에는 계정 시스템보다 브라우저 저장 등 작은 구현으로 검증할 수 있다. 이후 실제 사용 수요가 확인되면 동기화·회원 기능을 검토한다.

### D. 사람과 관계
- 풍류와 차 커뮤니티 연결
- 질문과 시음 경험
- 소규모 차모임
- 시음회와 클래스
- 산지 여행

새 자체 자유게시판을 서둘러 만들지 않는다. 사이트 안에서는 개인 기록과 지식 연결을 먼저 완성한다.

### E. 꽃과 차 생활문화
- 차와 꽃이 놓인 테이블
- 계절의 꽃과 차
- 플로리스트가 만드는 찻자리
- 환대와 선물
- 공간 스타일링
- 차모임의 꽃 연출
- 여행에서 만난 식물과 풍경

꽃과 차를 억지 상품 세트로 만들지 않는다. 실제 생활에서 만나는 장면을 축적한다.

## 6. 개발 우선순위

당분간 큰 방향은 아래 순서를 따른다.

1. 데이터·백과의 빈칸과 구조를 계속 보강
2. 홍차·보이차·녹차 중심의 공개 콘텐츠 확대
3. 이야기·현장 기록을 꾸준히 추가
4. 차생활 기능을 작은 단위로 실제 구현
5. 기록·비교·보관을 연결해 재방문 구조 구축
6. 풍류와 차 및 실제 사람의 경험 연결
7. 충분한 내실 뒤 시음·클래스·큐레이션·선택적 구매 연결
8. 더 먼 장기에는 산지 여행까지 확장

날짜를 정해 억지로 다음 단계로 넘어가지 않는다. 콘텐츠 깊이, 기능 완성도, 사용자 반응을 보고 이동한다.

## 7. 현재 단계에서 하지 않을 것

- 단독 TECHA 검색 정체성을 차 사이트가 가져오려 하지 않는다.
- TECHA Tea를 대형 쇼핑몰처럼 만들지 않는다.
- 꽃 사이트 첫 화면에서 차를 크게 홍보하지 않는다.
- 차 사이트를 검증 데이터 표만 가득한 사이트로 만들지 않는다.
- 기능이 없는 상태에서 ‘커뮤니티’나 ‘놀이터’를 과장해 홍보하지 않는다.
- 빈 공간을 채우기 위해 미검증 차 정보를 공개하지 않는다.
- 차 판매를 위해 평가와 콘텐츠를 왜곡하지 않는다.
- 초기 계획의 기록·비교·사람·여행 축을 삭제하지 않는다.
