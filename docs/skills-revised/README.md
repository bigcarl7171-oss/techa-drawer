# 긍정형 전환 적용본 (2026-08-14)

`docs/skill-rules-positive-reframe.md`의 A·C 분류를 실제로 반영한 스킬 파일 사본이다.

## 왜 여기 있나

스킬 원본은 이 레포가 아니라 `~/.claude/skills/synced/<이름>/SKILL.md`에 있고,
그 경로는 세션이 끝나면 사라진다. 그래서 수정본을 레포에 사본으로 남긴다.

## 반영하는 법

각 파일 내용을 스킬 편집 UI의 해당 스킬에 붙여넣으면 영구 반영된다.
`techa-brand-rules.md`는 원래 레포 파일이라 사본이 필요 없다 — 이미 반영됨.

| `techa-automation-workflow.SKILL.md` | 스킬: techa-automation-workflow |
| `techa-cardnews.SKILL.md` | 스킬: techa-cardnews |

## 무게 변화

문구 교체 위주라 분량은 사실상 그대로다 (총 2,236줄 → 2,240줄).
중복된 금지 꼬리를 지운 자리와, 대체 행동을 괄호로 접어 넣은 자리가 서로 상쇄됐다.

## 적용하지 않은 것

B 분류(파일 손상·법적 리스크를 막는 하드 제약)는 **금지형 그대로 뒀다.**
긍정형으로 풀면 구속력이 약해지는 규칙들이다 — hwpx의 run 삭제 금지,
온스크린 텍스트 금지, 저작권 사진 금지, 대비 미달 색의 글자 사용 금지 등.
단, 같은 줄에 "대신 쓸 수단"이 없던 항목에는 그것만 접어 넣었다.
