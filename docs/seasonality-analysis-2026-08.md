**(1) 7월~8월 초는 확실한 연중 최저 구간이다.**

오히려 **8월이 연중 최고(1.54)**다. 이벤트 수요가 빠진 자리를 개인 기념일 수요가 채우는 구조다.

→ **6~8월 비수기 전략의 정답은 명확하다: 이벤트 키워드를 버리고 「생일·기념일·프로포즈」 축으로 갈아탄다.**
프리저브드는 "안 시든다 = 기념일 기록용"이라는 서사가 이 축과 가장 잘 맞는다.

## 5. 생화 vs 프리저브드/비누꽃 — 계절성이 다른가

### 답: **다르다. 그리고 방향이 명확하다.**

같은 주(week) 안에서 각 카테고리의 **연중 최고 주가 언제인지**를 비교하면 차이가 드러난다.

| 카테고리 | 어버이날 주(5/4) | 연말·졸업 주(12/29) | **어느 쪽이 큰가** |
|---|---|---|---|
| 꽃선물(생화) | **100** | 93.8 | 어버이날 승 (+6.6%) |
| **프리저브드** | 6.84 | **8.68** | **연말 승 (+27%)** |
| **비누꽃** | 6.65 | **12.97** | **연말 승 (+95%)** |
| 돈꽃다발 | 18.82 | 13.10 | 어버이날 압승 (+44%) |

월지수로 봐도 같다.

| | 5월 | 12월 | 12월/5월 |
|---|---|---|---|
| 꽃선물(생화) | 129 | 147 | 1.14 |
| 프리저브드 | 111 | 136 | **1.23** |
| 비누꽃 | 104 | 190 | **1.83** |

### 해석 (근거 있는 부분과 없는 부분 구분)

**근거 있음 — 데이터로 확인된 사실:**
1. **생화는 5월(어버이날)이 최대, 보존화는 12~1월이 최대다.** 3년 연속 일관된다.
2. **비누꽃의 겨울 편중이 가장 극단적**이다(12월 190 vs 7월 50, 3.8배).
3. 프리저브드의 진폭(2.0배)이 생화(2.2배)보다 **작다** — 즉 비수기 방어력이 상대적으로 높다.

**추정 — 해석은 붙였으나 직접 검증되지 않음:**
- 보존화가 12~1월에 몰리는 이유로 「선물의 성격 차이」를 든다. 크리스마스·졸업은 **기념으로 남기는** 선물이고, 어버이날은 **당일 전달**이 목적이다. 시들지 않는 특성이 전자에서 더 팔린다는 가설이다. 검색어 조합만으로는 검증되지 않는다.
- 비누꽃의 12~2월 초강세는 **가격대(9,400~34,500원)** 때문일 가능성도 있다. 졸업·연말은 다수에게 소액 선물을 뿌리는 시즌이라 저가 상품이 유리하다. 이것도 미검증이다.

**⚠️ 자주 인용되는 "프리저브드는 계절과 무관하다"는 주장은 국내 데이터로는 틀렸다.**
해외 시장 보고서([stafroroses 등](http://ko.stafroroses.com/news/preserved-flower-market-report/))는 "계절·기후에 관계없이 접근 가능"을 프리저브드의 장점으로 든다. 이는 **생산·유통** 관점의 서술이지 **수요** 관점이 아니다.
실제 국내 검색 수요는 **연중 2.0배 변동**한다. 공급이 계절을 안 타는 것과 수요가 계절을 안 타는 것은 다른 이야기다.

## 8. 소스 간 충돌 — 네이버 vs 구글

| 항목 | 네이버 데이터랩 | 구글 트렌드 KR |
|---|---|---|
| 「프리저브드플라워」 | 정상 수집, 뚜렷한 계절성 | **52주 중 50주가 0** |
| 「비누꽃다발」 | 정상 수집 | **전 구간 0** |
| 「꽃선물」 어버이날 주 | **100 (연중 최고)** | **100 (연중 최고)** ✅ |
| 「꽃선물」 12월말 주 | **93.8 (2위)** | 40~55 (중위권) ❌ |
| 데이터 품질 | 결측 없음 | 결측 주 2회(값 0) |

**충돌 지점: 12월 성수기의 크기.** 네이버는 12월을 어버이날급으로 보고, 구글은 평범한 달로 본다.

**네이버를 채택한다. 근거:**
1. 구글 KR은 니치 키워드 2개를 **아예 측정 못 한다**(0). 표본이 임계 미달이라는 뜻이고, 「꽃선물」도 같은 표본 문제를 겪을 가능성이 높다. 실제로 정상 주에 0이 두 번 찍혔다 — 데이터 파이프라인이 신뢰할 수 없다는 직접 증거다.
2. 네이버는 3개 연도가 **독립적으로 같은 12월 피크**를 보여준다(2023-12, 2024-12, 2025-12 모두). 우연이 아니다.
3. 국내 이커머스 구매 검색은 네이버에서 일어난다. 구글은 정보 검색 비중이 높아 **구매의도 대리지표로 부적합**하다.
4. 두 소스가 **일치하는 지점**(어버이날 = 연중 최고)이 있다는 것은 네이버 데이터가 최소한 틀리지 않았음을 뒷받침한다.

**단, 네이버 데이터에도 한계가 있다:** 검색량 ≠ 구매량이다. 12월은 "선물 뭐 사지" 탐색 검색이 구매 검색보다 많이 섞여 있을 수 있다. 이 왜곡은 **네이버 데이터랩 쇼핑인사이트(클릭량 기반)** 로만 걷어낼 수 있는데, 이는 네이버 개발자 API 키가 필요해 이번엔 수집하지 못했다.

1. **프리저브드·돈꽃다발 예산을 지금 올린다.** 8월 셋째 주부터 시장이 30~50% 반등한다(2년 연속 검증). 두 라인은 이미 계절 패턴대로 움직이고 있어 추가 투입의 효율이 가장 좋다.
2. **무드등 부진을 "계절 탓"으로 정리하지 않는다.** 검색은 늘고 매출은 줄었다. 원인 규명 전까지 예산 동결 — 현재 광고비의 42%가 여기 있다.
3. **6~8월용 「생일·기념일·프로포즈」 키워드 축을 만든다.** 이 수요는 연중 평탄하고 8월이 오히려 최고치다. 내년 비수기(6~7월)를 방어할 유일한 축이다.

## 10. 1년 판매량 원본이 있으면 무엇이 정확해지는가

사장님이 **판매자센터 → 통계 → 판매분석**에서 뽑아 주시면 좋을 것들이다.

| # | 뽑을 자료 | 경로 | 이걸로 정확해지는 것 |
|---|---|---|---|
| 1 | **최근 13개월 일별 결제금액·결제건수** | 판매분석 > 판매성과 (기간 13개월, 일단위 CSV) | 검색량 프록시를 **실제 판매 곡선으로 교체**. 지금 문서의 모든 지수가 추정에서 사실로 바뀐다 |
| 2 | **상품별 × 월별 판매량** | 판매분석 > 상품성과 | 카테고리 지수가 아니라 **31개 상품 각각의 계절성**. "장미수국은 12월, 해바라기는 5월" 같은 상품 단위 판단이 가능해진다 |
| 3 | **월별 객단가·구매건수 분리** | 판매분석 > 판매성과 | 12월 매출 급증이 **건수 증가인지 객단가 상승인지** 구분. 전자면 신규 유입 전략, 후자면 세트/업셀 전략 |
| 4 | **월별 검색유입 키워드** | 마케팅분석 > 검색채널 | 이벤트별 실제 유입 키워드 확보 → 4장 리드타임 표를 **테차 실제 키워드 기준**으로 재작성 |
| 5 | **월별 재구매율·신규/재구매 비중** | 고객현황 | 성수기 유입 고객이 비수기에 돌아오는지 확인. 6~7월 방어 전략의 실효성 판단 근거 |
| 6 | 네이버 개발자센터 API 키 | developers.naver.com > 데이터랩 API | **쇼핑인사이트(클릭량 기반)** 수집 가능 → 8장에서 지적한 "검색량 ≠ 구매량" 왜곡 제거 |

### 특히 1번이 바뀌면 이 문서의 무엇이 달라지나

| 지금 문서 | 1년 판매 원본이 생기면 |
|---|---|
| 월별 지수 = 시장 검색 수요 추정 | **테차 실제 판매 계절성** (점유율 변화 포함) |
| "12월이 연평균의 1.4배" | "작년 12월 실매출 ○○○원, 올해 목표 ○○○원" |
| 리드타임 = 검색 시작 시점 | **구매 시작 시점** (검색보다 보통 며칠~1주 늦다) |
| 예산 배분 = 수요지수 비례 | **월별 실제 ROAS 기반 배분** |
| 8장 "불일치" 판정 = 광고 매출 기준 | 자연검색 포함 **총매출 기준**으로 재검증 |

**그중 하나만 고른다면 1번이다.** 13개월 일별 결제 데이터 하나면 이 문서의 추정 대부분이 사실로 승격된다.
