# 테차 꽃 구독 서비스 구성안 (2026-09-20)

`/space/` 의 "꽃 정기 구독"이 지금 한 문단뿐이라 무엇을 파는지 알 수 없다.
잘 굴러가는 곳을 조사해 **테차에 옮길 수 있는 것과 옮기면 안 되는 것**을 가른 뒤 구성했다.

> ⚠️ 이 문서는 **제안**이다. 주기·가격·회수 방식은 사장님이 정해야 확정된다.
> 정해지지 않은 칸은 "상담 시 함께 정합니다"로 두고 페이지를 만든다.

---

## 1. 조사 — 남들은 어떻게 하나

### 꾸까 (생화 B2C, 국내 최대)

| 항목 | 방식 |
|---|---|
| 주기 | **2주에 한 번** 고정 |
| 티어 | 꽃다발 라인 M·L·XL / 파머스믹스 S·M — 크기로만 가름 |
| 기간 | 1회 · 1개월 · 2개월 · 6개월 · 1년 중 선택 |
| 가격 | 9,900원부터 시작. 기간이 길수록 할인·사은품 |
| 배송 | 무료 |
| 팔고 있는 것 | "이번 주는 무슨 꽃일까" — **기대감**을 판다 |

출처: [꾸까 정기구독](https://kukka.kr/subscription/)

### 더포레스트 (화분 렌탈, B2B 중심)

| 항목 | 방식 |
|---|---|
| 범위 | 식물 선정 → 배송 → 설치 → **정기 관리**까지 원스톱 |
| 관리 | 전문 관리자가 주기적으로 방문해 상태 점검 |
| 대상 | 사무실 · 관공서 · 호텔 · 병원 · 학교 · 가정 |
| 가격 | **공개하지 않는다.** 견적 문의로 받는다 |
| 팔고 있는 것 | 물건이 아니라 **신경 안 써도 되는 상태** |

출처: [더포레스트](https://theforest3.co.kr/)

### 구독이 깨지는 지점

해지 조건이 불만의 핵심이다. "결제일 며칠 전까지 신청해야 다음 결제가 멈춘다"는 조항이
흔하고, 해지했다는 것을 소비자가 입증해야 하는 구조가 분쟁을 만든다.
배송 중 꽃이 상하는 것도 반복되는 불만이다.

## 2. 그대로 가져오면 안 되는 것

**생화 구독 구조를 복사하면 테차는 스스로를 부정하게 된다.**

| 남의 방식 | 테차에 안 맞는 이유 |
|---|---|
| 2주에 한 번 교체 | 테차 꽃은 시들지 않는다. 2주마다 바꿀 이유가 없고, 바꾸자고 하면 "안 시든다"는 말이 무너진다 |
| "이번 주는 무슨 꽃일까" | 생화라서 성립하는 기대감이다. 오래 두는 물건에는 잦은 변화가 오히려 피로다 |
| 크기로만 나눈 티어 | 테차 구독의 값은 크기가 아니라 **교체 횟수와 방문 여부**에서 갈린다 |
| 낮은 진입가(9,900원) | 시들지 않는 소재는 단가 구조가 다르다. 억지로 낮추면 구성이 빈약해진다 |

### 반대로 — 테차만 할 수 있는 것

생화 구독의 가장 큰 약점이 테차에는 없다.

> **중간에 멈춰도 이미 받은 것은 그대로 남는다.**

생화 구독은 해지하면 다음 주부터 아무것도 없다. 그래서 사람들이 시작을 망설인다.
테차는 3개월만 하고 멈춰도 그동안 받은 꽃이 그 자리에 그대로 있다.
**이건 홍보 문구가 아니라 사실이고, 구독을 권하는 가장 강한 근거다.**

## 3. 제안 — 구독을 세 갈래로 나눈다

하나의 "꽃 구독"으로 묶으면 설명이 흐려진다. **사는 이유가 서로 다르기 때문이다.**

| 갈래 | 누가 | 왜 정기적으로 사는가 |
|---|---|---|
| **A. 계절 구독** | 집·상업 공간 | 시들어서가 아니라 **계절이 바뀌어서** |
| **B. 선물 구독** | 챙길 사람이 여럿인 분 | 날짜를 놓치지 않으려고 |
| **C. 공간 관리 구독** | 기업·매장 | 신경 쓰지 않아도 되는 상태를 사려고 |

---

### A. 계절 구독 — 집과 상업 공간

**파는 것:** 계절이 바뀔 때 공간의 인상을 바꾸는 일.

| 항목 | 제안 | 결정 필요 |
|---|---|---|
| 주기 | **연 4회** (3·6·9·12월) | ⬜ 연 2회(봄·가을) 안도 가능 |
| 받는 것 | 그 계절 구성 1점 + 놓는 자리 안내 | |
| 기존 것 | 셋 중 하나 — ① 그대로 두고 늘려간다 ② 회수 후 보관 ③ 회수 후 다음 구성에 재사용 | ⬜ **가장 먼저 정해야 할 것** |
| 기간 | 1년 단위, 중도 중단 가능 | ⬜ |
| 배송 | 택배 (고양·서울은 퀵 또는 방문 수령) | |

**설명 문장(초안)**
> 꽃이 시들어서 바꾸는 것이 아닙니다. 계절이 바뀌면 같은 자리도 다르게 보입니다.
> 봄에는 밝은 색, 겨울에는 낮은 채도로 — 계절마다 한 번, 그 자리에 맞는 구성을 보내드립니다.
> 지난 계절 것은 그대로 두셔도 되고, 다음 구성에 함께 쓰실 수도 있습니다.

---

### B. 선물 구독 — 챙길 날이 여럿인 분

**테차에 가장 자연스러운 갈래다.** 오늘 발행한 매거진
[아내 생일 선물 편](/blog/wife-birthday-gift/)의 논리를 그대로 서비스로 만든 것이다.

부모님 두 분 생신 + 어버이날 + 명절만 해도 한 해에 네 번이다.
그때마다 따로 고르고 따로 주문한다. **그 일을 한 번에 정해두는 것**이 이 구독이다.

| 항목 | 제안 | 결정 필요 |
|---|---|---|
| 주기 | **날짜 지정형** — 정해진 날짜마다 (2~6회/년) | |
| 등록 | 받는 분·주소·날짜·메시지를 처음에 한 번 등록 | |
| 발송 | 날짜 며칠 전 확인 연락 → 발송 | ⬜ 며칠 전인지 |
| 바꾸기 | 발송 전까지 구성·날짜 변경 가능 | ⬜ 마감 시점 |
| 카드 | 회차마다 다른 문구 (`/message/` 문구 연결) | |

**왜 시들지 않는 꽃이어야 하는가 — 이 갈래의 핵심**
- 받는 분이 집을 비워도 꽃이 상하지 않는다. 날짜를 정확히 맞출 필요가 없다
- 해마다 쌓여도 부담이 아니라 **작년 것 옆에 올해 것**이 된다
- 멀리 계신 부모님께 물 갈아 드릴 사람이 없어도 된다

**설명 문장(초안)**
> 챙길 날이 여럿이면 매번 처음부터 고르게 됩니다.
> 받는 분과 날짜를 한 번 등록해 두시면 그때마다 준비해 보내드립니다.
> 시들지 않는 꽃이라 받는 분이 그날 집에 안 계셔도 괜찮고, 해마다 늘어나도 부담이 되지 않습니다.

---

### C. 공간 관리 구독 — 기업·매장

더포레스트 모델과 같은 결이다. **파는 것은 꽃이 아니라 신경 쓰지 않아도 되는 상태다.**

| 항목 | 제안 | 결정 필요 |
|---|---|---|
| 범위 | 상담 → 구성 → 설치 → **정기 점검** |  |
| 점검 | 분기 1회 방문, 상태 확인 후 정돈·부분 교체 | ⬜ 방문 가능 권역 |
| 교체 | 계절·프로모션에 맞춰 색감 변경 | |
| 대상 | 사무실 리셉션 · 회의실 · 쇼룸 · 매장 · 상담실 |  |
| 가격 | **공개하지 않고 견적** — 공간마다 다르다 | |
| 서류 | 견적서·세금계산서 발행 | |

⬜ **방문 점검이 가능한 권역을 먼저 정해야 한다.** 고양·서울만인지, 수도권 전체인지.
못 가는 지역에 정기 방문을 약속하면 지킬 수 없다.

## 4. 가격을 어떻게 다룰 것인가

**금액을 쓰지 않는다. 대신 무엇으로 값이 정해지는지를 밝힌다.**
이것만으로도 "얼마쯤 들겠구나"를 가늠하게 되고, 확인 안 된 수치를 쓰지 않아도 된다.

> 구독 비용은 세 가지로 정해집니다.
> **구성의 크기**(한 자리인지 공간 전체인지) · **연간 횟수**(2회인지 4회인지) ·
> **방문 여부**(택배로 받는지 직접 점검을 받는지).
> 상담 때 이 셋을 함께 정하고 견적을 드립니다.

⬜ 가격을 공개할지 말지는 사장님 판단이다. 참고로 **꾸까는 공개하고 더포레스트는 안 한다.**
개인 대상(A·B)은 공개하는 편이 진입을 낮추고, 기업 대상(C)은 견적형이 맞다.

## 5. 시작을 망설이지 않게 하는 장치

조사에서 나온 불만의 핵심은 **"한번 걸면 빠져나오기 어렵다"**였다.
테차는 이걸 정면으로 풀 수 있다.

| 장치 | 내용 | 왜 |
|---|---|---|
| **멈춰도 남는다** | 중단해도 그때까지 받은 꽃은 그대로 | 생화 구독이 절대 못 하는 말 |
| **한 회차 건너뛰기** | 이사·출장 등으로 못 받을 때 다음으로 미룸 | 해지 대신 쉬어가는 길 |
| **언제든 중단** | 다음 회차 준비 전에 말하면 중단 | ⬜ 며칠 전인지 정해야 함 |
| **첫 회차 먼저** | 한 번 받아보고 이어갈지 정함 | 구독이 처음인 사람의 가장 큰 벽 |

⬜ 네 가지 모두 사장님 확인이 필요하다. **약속할 수 없는 것은 쓰지 않는다.**
특히 "언제든 중단"은 제작이 이미 들어간 회차와 부딪힐 수 있어 기준이 필요하다.

## 6. `/space/` 에 어떻게 넣을까

지금 4종(개인·구독·기업·리스타일링)으로 나뉜 것이 겹친다. **구독을 축으로 다시 묶는다.**

```
① 히어로
② 어디부터 시작할지 — 일회성 스타일링 / 구독 세 갈래 비교 표
③ 구독 A 계절    — 표 + 설명 + 사진
④ 구독 B 선물    — 표 + 설명 + /message/ 연결
⑤ 구독 C 공간관리 — 표 + 설명 + 견적 안내
⑥ 구독이 처음이신 분께 — 5절의 네 가지 장치
⑦ 값은 이렇게 정해집니다 — 4절
⑧ 꽃과 공간을 함께 보는 이유 (기존 유지)
⑨ 상담부터 리스타일링까지 (기존 6단계 유지)
⑩ FAQ
⑪ 상담 준비물
```

### FAQ에 반드시 넣을 것

조사에서 나온 실제 마찰 지점이다.

- 중간에 그만두면 지금까지 받은 꽃은 어떻게 되나요
- 한 회차만 쉬어갈 수 있나요
- 기존에 받은 꽃이 쌓이는데 자리가 부족해지지 않나요
- 받는 사람이 집에 없어도 되나요 (선물 구독)
- 방문 점검은 어느 지역까지 되나요 (공간 관리)
- 구독하지 않고 한 번만 받아볼 수 있나요

## 7. 사장님이 정해야 하는 것 — 이것부터

페이지를 만들기 전에 아래가 정해져야 한다. **모르면 "상담 시 함께 정합니다"로 둔다.**

| # | 정할 것 | 없으면 |
|---|---|---|
| 1 | **계절 구독에서 기존 것을 회수하는가** | A 갈래를 쓸 수 없다. 가장 먼저 필요 |
| 2 | 연 몇 회로 할 것인가 (2회 / 4회) | "상담 시 정합니다" |
| 3 | 방문 점검 가능 권역 | C 갈래에서 "방문"을 빼고 택배 교체로만 |
| 4 | 중단·건너뛰기 기준 (며칠 전) | 5절 표를 빼고 "상담 시 안내" |
| 5 | 가격 공개 여부 | 전부 견적형으로 |
| 6 | 실제로 진행한 구독·공간 사례 유무 | 사례 절을 비우고 공방 사진으로 |

> 1번이 제일 중요하다. 회수하지 않고 쌓이는 구조라면 그것 자체가 이 구독의 성격이다 —
> "매번 새것으로 바꿔 드립니다"가 아니라 **"해마다 하나씩 늘려 갑니다"**가 된다.
> 테차 상품의 성질과는 뒤쪽이 훨씬 잘 맞는다.

## 8. 페이지를 쓸 때 지킬 것

- **금액·기간·권역을 확인 없이 쓰지 않는다.** 지키지 못할 약속이 된다
- **없는 사례를 만들지 않는다**
- 표·목록·FAQ는 전부 **정적 HTML**. 자바스크립트 안에 두지 않는다
- 구독 설명에서 "시들지 않는다"를 반복하지 말고, **그래서 무엇이 달라지는지**를 쓴다
  (날짜를 안 맞춰도 된다 / 멈춰도 남는다 / 관리할 사람이 없어도 된다)
