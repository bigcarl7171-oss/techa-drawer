# 테차 쇼츠 자막 시스템 (1분 이내 제품 광고)

> **상위 규칙**: `techa-brand-rules.md` §5(모션·영상 공통) · §3-2-1(사진 위 대비) · §3-4(폰트 굵기).

> 상위 규칙과 어긋나면 상위 규칙이 이긴다. 여기서 새 색·새 폰트·새 움직임을 만들지 않는다.

## 1. 왜 고정해야 하나

지금 테차 영상은 만들 때마다 자막이 다르다. 폰트·크기·위치·등장 방식이 매번 달라지면
영상 10개를 봐도 같은 브랜드로 인식되지 않는다. **자막은 로고보다 화면에 오래 떠 있다.**
1분짜리 영상에서 로고는 2초, 자막은 50초 넘게 떠 있다. 브랜드를 기억시키는 실제 지분은
자막 쪽이 훨씬 크다.

---

## 2. 레퍼런스 분석 — 잘하는 곳은 무엇을 고정했나

브랜드를 4개 축으로 나눠 봤다. **각각이 무엇을 고정했고, 테차가 무엇을 가져올 수 있는지**만 본다.

### 2-1. 애플 — "자막은 받아쓰기가 아니라 화면의 한 요소다"

- 폰트 1종(SF Pro), 색은 순백 또는 순흑만. **그라디언트·외곽선·그림자 없음.**
- 한 화면에 한 구절. 등장·퇴장이 음악과 보이스오버에 정확히 물린다.
- 영상용 자간을 인쇄보다 넓게 잡는다 — 화면의 글자는 숨 쉴 공간이 더 필요하다.

**가져올 것**: 장식을 뺄수록 브랜드가 선명해진다. 이미 §5-6-2(외곽선 금지)로 같은 결론에 와 있다.
**못 가져올 것**: 애플은 제품 인지도가 있어서 훅 없이 시작해도 된다. 테차는 첫 3초를 잡아야 한다.

### 2-2. 배달의민족 — "폰트 고정이 로고 노출보다 강하다"

- 전용 폰트(한나체·을지로체)가 그 자체로 식별자다. 로고가 안 보여도 자막 한 줄이면 어디인지 안다.

**가져올 것**: 이게 테차의 **최대 미사용 자산**이다. §3-4에 이미 Gowun Batang이라는 희소한
세리프를 브랜드 폰트로 못 박아뒀는데, 영상에서는 쓰이지 않고 있다. 고딕 일색인 숏폼 피드에서
세리프 훅 한 줄은 그 자체로 눈에 띈다. **워터마크를 키우는 것보다 이게 먼저다.**

### 2-3. 커머스 정보형 자막(오늘의집 계열) — "강조는 하나만"

- 굵은 고딕 + 반투명 카드 + **키워드 하나만** 강조 + 문장 단위 교체.
- 소리를 꺼도 100% 이해된다(§5-3과 같은 전제).

**가져올 것**: 강조 어절은 자막 하나당 **최대 1개**. 문장 전체를 강조하면 아무것도 강조되지 않는다.
**변형해야 할 것**: 이들은 글자 색을 바꿔 강조하는데, §3-2-1이 사진 위 색 강조를 금지한다.
→ 테차는 **색이 아니라 골드 밑줄 면**으로 강조한다.

### 2-4. 감성 뷰티·향 브랜드 — "무드가 자산이면 자막을 줄인다"

- 자막이 거의 없다. 있어도 라틴 대문자 한 줄, 아주 느린 페이드.

**가져올 것**: 조용한 타이포가 곧 가격대를 말한다.
**못 가져올 것**: 테차는 2~5만 원대 선물이라 "무드만 있고 설명이 없으면" 안 팔린다.
가격·구성·배송은 반드시 화면에 있어야 한다(§5-3).

### 2-5. 반대 레퍼런스 — 편집 앱 기본 밈 자막

흰 굵은 고딕 + 검정 두꺼운 외곽선 + 단어별로 튀는 팝. **가장 흔하기 때문에 브랜드가 지워진다.**
§5-6-1에 이미 금지로 박혀 있다. 여기서 다시 확인만 한다.

### 2-6. 결론 — 테차의 좌표

> 애플·감성 브랜드의 **조용한 타이포**와 커머스의 **정보형 자막** 사이 어디에도 그냥 서면 안 된다.
> 대신 **레이어를 나눈다** — 훅은 커머스처럼 세게, 본문은 조용하게, 정보는 칩으로 분리.

이게 아래 3장의 구조다.

## 3. 자막 레이어 4종 (이 4개 외에는 만들지 않는다)

| 레이어 | 역할 | 폰트 | 굵기 | 크기 | 위치 |
|---|---|---|---|---|---|
| **L1 훅** | 0~3초, 스크롤을 멈추게 한다 | Gowun Batang | 700 | **92px** | 안전영역 상단에서 아래로 120px |
| **L2 자막** | 본문 내레이션 | Pretendard | 500 | **60px** | 바닥에서 500~820px (§5-5 고정) |
| **L3 정보칩** | 가격·구성·소재 | Pretendard | 600 | **40px** | L2 블록 바로 위 40px |
| **L4 엔드카드** | 마지막 2~3초 | Gowun Batang | 700 | **76px** | 안전영역 중앙 |

크기는 §3-4의 굵기 스케일을 그대로 따랐다. 훅과 엔드카드에만 세리프를 쓰는 이유는
§3-4의 "세리프는 굵기가 아니라 크기로 힘을 낸다" 원칙 때문이다 — Gowun Batang은 700이 상한이라
**작게 쓰면 힘이 안 실린다.** 그래서 세리프는 큰 자리에만 놓고, 작은 글자는 전부 Pretendard로 간다.

### 3-1. 줄당 글자수 (안전영역 폭 890px에서 나온 값)

한글은 전각이라 글자 폭 ≈ 폰트 크기다. 안전영역 폭 890px(§5-5)을 글자 크기로 나눈 값이 상한이다.

| 레이어 | 계산 | 한 줄 상한 | 줄수 상한 |
|---|---|---|---|
| L1 훅 | 890 ÷ 92 = 9.6 | **9자** | 2줄 |
| L2 자막 | 890 ÷ 60 = 14.8 | **14자** | 2줄 |
| L3 칩 | 890 ÷ 40 = 22.2 | 22자 (권장 12자) | 1줄 |
| L4 엔드카드 | 890 ÷ 76 = 11.7 | **11자** | 2줄 |

⛔ **2줄을 넘기지 않는다.** 넘으면 문장을 쪼갠다.
※ §4의 "한 줄 45자"는 읽는 원고 기준이다. 영상은 보는 글이라 기준이 다르다.

### 3-2. 행간·자간

| 레이어 | 행간 | 자간 | 이유 |
|---|---|---|---|
| L1 훅 | 1.25 | **-2%** | 큰 세리프는 조여야 한 덩어리로 읽힌다 |
| L2 자막 | 1.35 | **+2%** | 작은 글자는 벌려야 사진 위에서 안 뭉친다 |
| L3 칩 | 1.2 | 0 | — |
| L4 엔드카드 | 1.3 | -2% | L1과 동일 |

### 3-3. 색과 배경

§3-2-1을 그대로 따른다. **글자색은 크림 `#FAF3EA` 또는 브라운 deep `#26201C` 둘 중 하나뿐이고,
반드시 스크림을 깐다.**

| 레이어 | 기본 처리 |
|---|---|
| L1 훅 | 크림 글자 + **그라디언트 스크림**(§3-2-1 ①), 화면 상단 35% |
| L2 자막 | 크림 글자 + **그라디언트 스크림**(①), 화면 하단 35% |
| L3 칩 | 크림 글자 + **솔리드 밴드**(②) `#26201C` 85%, 모서리 8px |
| L4 엔드카드 | 크림 배경 `#FAF3EA` 전면 + 브라운 `#3A322B` 글자 (사진 없음 → §3-2 표 그대로) |

⛔ 골드·세이지·핑크는 글자색으로 쓰지 않는다. ⛔ 외곽선 금지.

### 3-4. 엔드카드(L4) 구성

로고 + CTA 두 줄. CTA는 `techa-brand-rules.md` §4-3의 세트에서 **목적에 맞는 하나만** 고른다.
여기서 새로 쓰지 않는다.

| 우선순위 | 목적 | 1줄 | 2줄 |
|---|---|---|---|
| **기본값** | 전환형 — 특정 상품을 다룬 영상 | 변치 않는 선물, | 스토어에서 기다릴게요 |
| 2순위 | 상담형 — 맞춤 제작이 소재인 영상 | 원하시는 대로, | 맞춤 제작해드려요 |
| 3순위 | 관계형 — 특정 상품을 말하지 않는 영상 | 다음 꽃도 | 보여드릴게요 |

- 목적이 애매하면 **전환형**을 쓴다.
- **엔드카드 구간에는 좌상단 워터마크를 뺀다** — 큰 로고와 중복이다(§3-4).
- 로고 색은 크림 배경 위이므로 공방 브라운 `#3A322B`(§3-2).

## 4. 애니메이션 4종 (이 4개 외에는 쓰지 않는다)

전부 §5-1(이징·이동거리·스케일)과 §5-2(지속시간)에서 그대로 나온 값이다.

### ① 페이드 라이즈 — 모든 자막의 기본

```
등장: opacity 0 → 1,  Y +24px → 0
      240ms,  cubic-bezier(0.22, 1, 0.36, 1)
퇴장: opacity 1 → 0
      160ms,  cubic-bezier(0.4, 0, 1, 1)   ※ 나갈 때는 움직이지 않는다
```
L1·L2·L4에 쓴다. 2줄일 때는 둘째 줄을 **80ms 늦게**(§5-2 stagger) 띄운다.

### ② 밑줄 와이프 — 강조 (자막 하나당 최대 1어절)

```
골드 #C9A961 밑줄 면이 좌 → 우로 늘어난다
높이 6px,  글자 아래 8px
200ms,  cubic-bezier(0.22, 1, 0.36, 1)
자막이 뜨고 120ms 뒤에 시작
```
⛔ **글자 색은 바꾸지 않는다.** 골드는 §3-2-1에서 사진 위 글자색으로 금지다.
밑줄은 면이라 금지 대상이 아니고, 골드를 브랜드 색으로 쓸 수 있는 유일한 통로다.

### ③ 칩 스케일 — L3 정보칩

```
opacity 0 → 1,  scale 0.96 → 1.0
240ms,  cubic-bezier(0.22, 1, 0.36, 1)
```
여러 칩은 80ms 간격으로 순차 등장. ⛔ 동시에 3개 이상 띄우지 않는다(§5-1 동시 움직임 2개).

### ④ 엔드카드 — 마지막 2~3초

```
크림 배경 디졸브        300ms
로고 페이드            400ms
그 아래 한 줄          로고보다 80ms 늦게, 페이드 라이즈(①)
```

### ⛔ 쓰지 않는 애니메이션

- **단어별 팝 / 카라오케 하이라이트** — §5-6-1. 가장 흔한 기본값이라 브랜드가 지워진다.
- **타자기 효과** — 읽는 속도를 시청자가 아니라 편집자가 정하게 된다.
- **바운스·회전·셰이크** — §5-1 금지 목록.
- **글자 색이 바뀌는 강조** — ②로 대체한다.

## 5. 타이밍 규칙

| 항목 | 값 |
|---|---|
| 자막이 음성보다 먼저 뜨는 시간 | **120ms** (읽는 속도가 듣는 속도보다 빠르다) |
| 한 자막이 머무는 시간 | **1.5~3초** |
| 자막 교체 사이 공백 | **200ms** (눈이 리셋할 시간) |
| 한 자막이 화면에 머무는 최대 | **3초** — 넘으면 화면이 멈춘 것처럼 보이니 문장을 쪼갠다 |

⛔ 음성보다 **300ms 이상 먼저** 띄우지 않는다. 화면과 소리가 따로 노는 것처럼 보인다.

### 5-1. 60초 영상 시간 배분 예시

| 구간 | 시간 | 레이어 |
|---|---|---|
| 훅 | 0~3초 | L1 (이 3초 동안 자막을 바꾸지 않는다) |
| 공감·문제 | 3~15초 | L2 |
| 제품·장점 | 15~40초 | L2 + L3 |
| 안심(배송·구성) | 40~52초 | L2 + L3 |
| 엔드카드 | 52~60초 | L4 |

## 6. 도구에 고정하는 방법

수치를 문서에만 적어두면 지켜지지 않는다. **편집 도구 안에 스타일로 저장해서
매번 새로 만들지 않게 한다.**

| 도구 | 방법 |
|---|---|
| Premiere Pro | 기본 그래픽(Essential Graphics)에 **마스터 스타일 4종**(L1~L4) 저장. 저장해두면 나중에 스타일 하나만 고쳐도 전체 자막이 한 번에 바뀐다 |
| CapCut | 텍스트 → 스타일 저장. L1~L4를 각각 템플릿으로 |
| Canva | 브랜드 키트에 폰트·색 등록(§3-4의 로고 원본이 이미 등록되어 있다) |

- **세이프존 오버레이 PNG**(1080×1920, §5-5 수치)를 만들어 편집 프로젝트 최상단에 깔고 작업한다.
  내보낼 때만 끈다.
- 기존 텍스트 요소를 복사해 재활용하면 **원본 폰트가 그대로 남는다**(§3-4의 해바라기 카드뉴스 사고).
  반드시 저장된 스타일을 적용한다.

## 7. 발행 전 체크리스트

- [ ] 폰트가 Gowun Batang·Pretendard **2종뿐**인가 (§3-4)
- [ ] 글자색이 크림·브라운 deep **2색뿐**이고 전부 스크림 위에 있는가 (§3-2-1)
- [ ] 외곽선(스트로크)이 하나도 없는가 (§5-6-2)
- [ ] 자막이 **2줄을 넘지 않는가**, 훅 9자·자막 14자 안에 들어오는가 (3-1)
- [ ] 자막 위치가 바닥에서 500~820px에 고정되어 있는가, 영상 중간에 움직이지 않는가 (§5-5)
- [ ] **소리를 끄고 처음부터 끝까지** 봤을 때 메시지가 전부 전달되는가 (§5-3)
- [ ] 자막이 제품을 가리는 컷이 없는가 (§5-6-8)
- [ ] 강조가 자막 하나당 1어절 이하인가 (4-②)
- [ ] 실제 폰으로 한 번 돌려봤는가 (§5-5)
