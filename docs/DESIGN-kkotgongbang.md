# 테차 꽃공방 웹 디자인 규칙 (2026-09-22~)

techa.kr 의 화면을 만들 때 따르는 규칙이다. **새 페이지·새 칸을 만들거나 고칠 때 이 문서부터 연다.**
값을 바꾸면 코드(`assets/css/home.css`, `assets/css/style.css`)와 이 문서를 같이 고친다.

| 무엇 | 어디가 정본인가 |
|---|---|
| 브랜드 색 값·대비 규칙·로고 | `techa-brand-rules.md` §3 (카드뉴스·쇼츠·사이트 공통) |
| **웹에서 그 색·글꼴을 어떻게 쓰나** | **이 문서** |

> 루트의 `DESIGN-techa.md` 는 **폐기**다. 생활 도구 사이트(테차 툴즈·테차 서랍) 시절의

## 왜 바꿨나 (2026-09-22)

사장님 진단: "왼쪽 배너와 테차 꽃공방·설명 부분이 겉돌고 B급 브랜드 느낌이다."
원인은 메인이 도구 사이트의 옷을 입고 있던 것이었다.

- 로고·이름·설명은 가운데 정렬, 바로 아래 메뉴는 왼쪽 정렬 → 로고 영역만 떠 보였다
- 굵은 영문 로고, 명조 한글 이름, 작은 회색 설명이 크기·굵기·색이 제각각 → 목소리가 셋
- 왼쪽 메뉴 + 본문 + 오른쪽 칸을 둥근 틀에 넣은 대시보드 → 관리 화면 인상
- 알약 버튼·테두리 칸·작은 라벨이 반복 → 모든 것이 같은 무게

시안 두 개(에디토리얼 헤더형 / 사이드바 정돈형) 중 사장님이 **에디토리얼 헤더형**을 골랐다.
시안 페이지: https://claude.ai/artifact/JhR1AHjXSxSeNBaXn1R8Ky

## 원칙 다섯 가지

1. **절제가 고급이다.** 한 화면에 강조는 하나. 나머지는 조용히 둔다.
2. **구분은 선과 여백으로.** 카드 테두리·그림자·둥근 상자를 기본으로 쓰지 않는다. 1px 선과 충분한 여백이 칸을 나눈다.
3. **사진이 먼저 말한다.** 첫 화면과 이야기 칸은 사진이 절반을 차지한다. 가능하면 공방 실사를 쓴다.
4. **브랜드는 한 덩어리.** 로고, 이름, 슬로건을 따로따로 흩지 않는다.
5. **이모지로 표시하지 않는다.** 섹션 표식·카드 태그·메뉴·버튼에 이모지를 쓰지 않는다. 아이콘이 필요하면 1.6px 선 아이콘(SVG).

## 구성 요소

### 공통 머리말 (모든 페이지 같은 모양)
```
[techa 로고]      선물 추천  꽃 선물 메시지  테차 매거진  공간 스타일링  기업·단체 주문      (검색)  [스마트스토어 ↗]
 테차 꽃공방
```
- 로고 영역: 영문 로고 이미지 위, "테차 꽃공방" 아래(명조 11.5px, 자간 .2em). 사장님이 고른 순서.
- 메뉴 다섯 개, 가운데 정렬. "테차 소개·꽃 관리법"은 푸터와 휴대폰 메뉴에만.
- 스토어는 선 버튼 하나. 가리키면 브라운으로 채워진다.
- 980px 이하: 가운데 메뉴를 숨기고 **"메뉴" 버튼(`<details>`)** 으로 접는다. 자바스크립트 없이 열린다.

### 버튼 — 두 종류뿐
| | 모양 | 쓰는 곳 |
|---|---|---|
| 진한 버튼 `.h-btn-dark` | 브라운 바탕 · 크림 글자 | 화면마다 가장 중요한 행동 하나 (1분 선물 추천받기, 스마트스토어에서 보기) |
| 선 버튼 `.h-btn-line` | 투명 바탕 · 브라운 1px 테두리 | 두 번째 행동 (카드 문구 찾기) |
| 글자 링크 `.h-more` `.h-arrow` | 밑줄 1px, 가리키면 골드 딥 | "전체 보기 →", "상담하기 →" |

### 섹션 머리
라벨(한국어·골드 딥) → 제목(명조) 을 왼쪽에, "전체 보기 →" 링크를 오른쪽 아래에. 휴대폰에서는 세로로 쌓는다.

### 카드
- 상품·매거진 카드는 **테두리 없이** 사진 + 라벨 + 제목 + 한 줄. 가리키면 제목에 골드 밑줄.
- 상황·도구 목록은 카드가 아니라 **표처럼** — 위에 브라운 선 한 줄, 칸 사이 세로선.

### 어두운 띠 (공방 이야기)
화면 가로를 채우는 `#26201C` 띠 한 곳. 사진 반 + 글 반. 약속 목록은 가는 선으로 나눈다.
한 페이지에 **한 번만** 쓴다 — 두 번 쓰면 강조가 사라진다.

### 휴대폰 하단 고정 바 (메인)
선물 추천(진한) · 메시지 찾기(선) · 선물 보기 ↗(골드 바탕). 스토어 판매가 1순위 목적이라 스토어 버튼을 뺀 적이 있으면 되돌린다.

## 메인 섹션 순서

목적 순위(스토어 판매 → 브랜드 신뢰 → 기업 문의, `docs/techa-drawer-definition.md`)대로 위에서 아래로.

1. 공통 머리말
2. 첫 화면 — 슬로건 → 제목 → 선물 추천 / 카드 문구 버튼 → 사진
3. 신뢰 한 줄 — 평점 · 직접 제작 · 시들지 않는 꽃 · 택배·방문 수령
4. 이달의 꽃 선물 — `build-home-curation.js` 가 채운다(월별)
5. 상황별 선물 — `build-home-curation.js` 가 채운다 + 자주 찾는 선물 링크
6. 꽃 선물 메시지
7. 테차 꽃공방 이야기 (어두운 띠) — 20년 디자이너 · 약속 세 가지
8. 테차 매거진 — `publish-draft.js` 가 최신 3편을 채운다
9. 꽃공방 서비스 — 공간 스타일링·정기구독 / 기업·단체 주문 + 납품해 온 곳
10. 선물 준비 도구 — `build-home-tools.js` 게이트가 링크 구성을 검사한다
11. 마무리 — 스마트스토어로 가는 마지막 한 줄

생성 칸의 `<!-- BEGIN … -->` / `<!-- END … -->` 표식은 옮겨도 되지만 지우면 안 된다.

## 새 칸을 만들기 전에 — 체크리스트

- [ ] 이모지를 넣지 않았는가 (표식·태그·버튼·메뉴 전부)
- [ ] 라벨이 한국어인가, 영어 대문자·장식용 번호가 아닌가
- [ ] 테두리 상자·그림자·알약 버튼 대신 선과 여백으로 나눴는가
- [ ] 진한 버튼은 화면당 하나인가
- [ ] 크림 위에 골드(#C9A961) 글자를 쓰지 않았는가 (글자는 골드 딥 #9E8551)
- [ ] 제목이 어구 중간에서 끊기지 않는가 (넓은 화면·휴대폰 둘 다 캡처로 확인)
- [ ] 머리말을 바꿨다면 `build-chrome.js` 와 `site.js` 를 둘 다 고쳤는가
- [ ] PC(1280·1440)와 휴대폰 폭으로 찍어 확인했는가
