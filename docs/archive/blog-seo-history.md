# 매거진 발행 규칙 — 폐기된 경위 모음 (보관)

`blog-seo-guide.md` 가 이 서사들을 본문에 안고 있어 17KB까지 불었다. 현행 절차를 읽는 데
방해가 돼서 2026-09-07에 여기로 옮겼다. **결론을 새 작업 근거로 쓰지 말 것** — 아래는
"왜 지금 규칙이 이런가"를 되물을 때만 본다.

---

## 1. 자수를 `wc -m` 이 3배로 부풀렸던 버그 (2026-08-23 발견)

`wc -m` 은 로케일이 UTF-8 이 아니면 문자가 아니라 바이트를 센다. 한글은 3바이트라
분량이 3배로 표시됐고, 그래서 분량 경고가 한 번도 안 걸렸다. 표시값 2,156~6,232자였던
14편의 실제 본문은 746~2,152자(중앙값 약 1,380자)였다.

- `check-publish.sh` 는 이후 UTF-8 로케일(C.UTF-8 등)을 찾아 그걸로 센다. 없으면 바이트
  수라도 내되 "신뢰도" 경고를 띄운다.
- 교훈: 숫자를 인용할 때 그 숫자가 **어떻게 측정됐는지**까지 본다.

## 2. 분량 하한 1,200 → 1,800 → 1,500

- 최초 "1,200~1,800자" 는 영문 SEO 기준 "1,500~2,500단어" 를 잘못 환산한 값이었다
  (영어 1,500~2,500단어 ≈ 한글 2,500~4,000자).
- 2026-08-19: 하한을 1,800으로 올림 — 근거로 든 "실제 발행글은 이미 1,835~2,718자"가
  위 1번의 부풀려진 값이었다.
- 2026-09-03: 1,500으로 내림. 구글·네이버 어느 쪽도 글자 수를 랭킹 요소로 쓰지 않고,
  하한의 목적("얇은 글 방지")에는 1,500이면 충분하다는 재확인. 1,800을 지키려 문단을
  늘리다 늘어진 사고(`autumn-flower-gift-offseason`, 세 번 늘렸다)가 결정타.
- **현행 값과 근거는 `docs/channel-specs.md`.**

## 3. 네이버 링크백 금지 (2026-08-07 방침 변경)

원래는 "네이버 블로그 글 끝에 techa.kr 매거진 링크를 건다"였다. 상업적 외부 링크가
반복되는 블로그를 네이버가 저품질로 판정할 수 있다는 우려로 폐기(네이버 공식 정책은
아니지만 감수할 이유가 없음). 대신 본문에는 브랜드명 "테차"만 언급, 링크가 꼭 필요하면
블로그 프로필·소개 영역에 1회성으로. 이 변경은 `techa-content-studio` 스킬에 먼저
반영됐고 `blog-seo-guide.md` 만 열흘 낡아 있어 그 사이 낡은 규칙대로 링크를 넣은 원고가
실제로 작성됐다 → **원고 규칙이 어긋나면 `techa-content-studio` 가 최신.**

## 4. 매거진 목록/링크: JS 렌더링 → 정적 HTML (2026-07-28)

`site.js` 의 `POSTS` 배열 + `renderMagazineTeaser`/`renderMagazineList` 로 글 목록을
JS 로 그리던 방식을 버리고, 글 링크를 HTML 소스에 직접 쓰는 방식으로 바꿨다. 네이버
크롤러(Yeti)가 구글봇보다 JS 렌더링을 신뢰할 수 없게 처리해서, JS 가 런타임에 만든
`<a>` 링크를 네이버가 아예 못 볼 수 있기 때문. (이 원칙은 현행이라 `blog-seo-guide.md`
본문에 요약이 남아 있다.)

## 5. 애드센스 → 브랜드 보조사이트 (2026-07-28)

테차 서랍의 목적이 "광고 수익 사이트"에서 "테차 프리저브드 플라워 브랜드의 검색 노출을
키우는 보조 사이트"로 바뀌었다. `docs/archive/monetization-strategy.md` 참고. 매거진 글의
평가 기준도 "애드센스 승인 기준"이 아니라 순수 검색 노출·브랜드 신뢰로 바뀌었다.
