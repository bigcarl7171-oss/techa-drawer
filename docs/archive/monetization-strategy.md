# 유틸리티 앱 100선 — 트래픽 유도 & 수익화 전략 (목표: 비용 대비 3배+ 수익)

> 핵심 원칙: **트래픽을 "사는" 게 아니라 "검색으로 얻는다".**
> 비용을 0에 수렴시키면 3배는 최소선이고, 실제로는 수십~수백 배 ROI가 목표가 된다.

---

## 1. 두 가지 수익 모델 — 무엇을 선택할 것인가

### ❌ Model B: 유료 트래픽 아비트라지 (광고 사서 → 광고로 수익) — 비추천
| 단계 | 한국 현실 숫자 |
|---|---|
| 구글애즈 CPC | ₩50~500 |
| 방문 1,000명 구매 | ₩50,000~500,000 |
| 발생 광고 조회 | 약 2,000 PV |
| 유틸리티 애드센스 RPM | ₩1,000~5,000 / 1,000PV |
| 실제 수익 | ₩2,000~10,000 |

➡️ **광고비 5만 원 → 수익 1만 원 = 손실.** 유틸리티 단가로는 3배 불가능.
➡️ 애드센스 정책상 "저가 유료유입 후 광고 도배"는 **계정 정지 사유**. 하지 말 것.

### ✅ Model A: 유기적 검색(SEO) 트래픽 — 채택
| 항목 | 금액 |
|---|---|
| 정적 호스팅 (Cloudflare Pages / Vercel / Netlify) | 0원 (무료 티어가 월 수백만 PV 커버) |
| 서버 비용 (브라우저 내 처리 = client-side) | 0원 |
| 도메인 | 연 ₩15,000 (월 ≈ ₩1,250) |
| **월 고정비** | **약 ₩1,250** |

➡️ 비용이 거의 0 → **손익분기 매우 낮음 → 3배는 트래픽 조금만 붙어도 달성.**

---

## 2. 수익 구조 & 현실적 RPM (반드시 숙지)

**RPM = 1,000 페이지뷰당 광고 수익.** 이게 전부다.

| 트래픽 규모 | 광고 네트워크 | 예상 RPM(한국/혼합) |
|---|---|---|
| 시작~월 1만 | Google AdSense | ₩1,000~5,000 |
| 월 1만+ | Ezoic (AdSense보다 1.5~2배) | ₩2,000~8,000 |
| 월 5만 세션+ | Mediavine | ₩5,000~15,000 |
| 월 10만+ | Raptive(구 AdThrive) | ₩6,000~20,000 |

**카테고리별 단가 차이 (중요):**
- 🔥 높음: 금융/대출/보험/부동산/자동차 (광고주 경쟁 치열)
- 🟡 중간: 건강/직장/교육/생활요금
- 🧊 낮음: 재미/별자리/개발자도구 (단, 트래픽·공유량은 큼)

➡️ **전략**: 재미 앱으로 트래픽 볼륨을 키우고, 금융/부동산 앱으로 수익 단가를 끌어올린다. 둘을 섞어야 최적.

## 3. 수익 = PV × RPM — 목표 시나리오

| 단계 | 앱 수 | 앱당 월 PV | 총 월 PV | RPM | 월 수익 | 월 비용 | ROI |
|---|---|---|---|---|---|---|---|
| 6개월 | 30 | 1,000 | 3만 | ₩2,000 | ₩6만 | ₩1,250 | 48배 |
| 12개월 | 70 | 3,000 | 21만 | ₩3,000 | ₩63만 | ₩1,250 | 500배 |
| 18개월 | 120 | 5,000 | 60만 | ₩4,000 | ₩240만 | ₩1,250 | 1,900배 |
| 24개월 | 140+ | 7,000 | 100만 | ₩5,000 | ₩500만 | ₩2,000 | 2,500배 |

➡️ "비용의 3배"는 **1단계에서 이미 훌쩍 넘는다.** 진짜 목표는 절대 수익(월 PV)을 키우는 것.

## 4. 트래픽 유도 방법 (핵심 실행)

### (1) 구조: 1앱 = 1URL + 설명 콘텐츠
- 절대 한 페이지에 몰지 않는다. 앱마다 독립 URL.
- 각 페이지에 300자+ 설명(사용법/공식/예시/주의) → 애드센스 "저품질" 회피 + SEO 상위.

### (2) 롱테일 키워드 공략
- 대형 키워드("계산기")는 포기. **구체 키워드**를 노린다.
  - 예: "만나이 계산기" → "빠른년생 만나이", "2026 만나이 계산"
- 앱 1개가 여러 롱테일 키워드로 유입 → 100개면 수천 개 키워드 커버.

### (3) 내부 링크로 세션당 PV↑ (수익 직결)
- 관련 앱끼리 연결: BMI ↔ 표준체중 ↔ 기초대사량 ↔ 다이어트칼로리
- 한 사람이 3~4개 앱을 돌면 광고 조회가 3~4배 → **수익 3~4배.**

### (4) SEO 기본기
- `<title>`·메타 설명에 핵심 키워드
- 구조화 데이터(schema.org) 적용
- 페이지 속도 최적화(정적+client-side라 유리)
- 모바일 최적화 필수(트래픽 70%+ 모바일)

### (5) 공유 바이럴 (재미 앱)
- 결과를 이미지 카드로 → "공유하기" 버튼 → 광고비 0으로 유입 확산
- 궁합/테스트/운세/메뉴추천이 여기에 강함.

### (6) 초기 부스팅(SEO 걸릴 때까지 6~12개월 보완)
- 관련 커뮤니티/카페/SNS에 도구 공유
- 무료 백링크(디렉토리 등록, 관련 블로그)
- ⚠️ 유료 트래픽은 "브랜드 인지"용 소액만. 아비트라지 목적 금지.

---

## 5. 애드센스 승인 & 정책 (실패 1순위 지점)

1. **승인 전 준비**: 도구 15~20개 + 각 설명 콘텐츠 + 개인정보처리방침/문의 페이지.
2. **"저품질 콘텐츠" 회피**: 도구만 X → 반드시 설명·예시·공식 동반.
3. **금지**: 유료 저가 트래픽 유입, 자가 클릭, 광고 과다 배치.
4. **광고 배치**: 콘텐츠 대비 광고가 너무 많으면 거절. 1스크린 1~2개 권장.

## 6. 90일 실행 로드맵

### Phase 1 (0~30일): MVP & 배포
- [ ] 우선순위 Top 10~15 앱 제작 (수요↑·경쟁↓·제작쉬움·정확도부담X)
  - 추천 출발: 만나이·D-day·글자수·로또추첨·사다리·메뉴룰렛·단위변환·연봉실수령·전기요금·꽃말
- [ ] 각 앱 개별 URL + 설명 콘텐츠 300자+
- [ ] 정적 호스팅 배포(Cloudflare Pages 등) + 도메인 연결
- [ ] 개인정보처리방침·문의 페이지
- [ ] Google Search Console·Analytics 등록, 사이트맵 제출

### Phase 2 (30~60일): 확장 & 애드센스
- [ ] 앱 30~50개로 확장
- [ ] 애드센스 신청 → 승인
- [ ] 내부 링크 구조 완성(카테고리 허브 페이지)
- [ ] 각 앱 SEO 최적화(title/schema/속도)

### Phase 3 (60~90일+): 트래픽 & 수익 최적화
- [ ] 앱 100개 목표
- [ ] 검색 유입 데이터 보고 잘 되는 앱 파생 확장
- [ ] 월 1만+ 되면 Ezoic 전환 검토 → 5만+ Mediavine
- [ ] 공유 기능·재방문 요소(운세·메뉴) 강화

## 7. 성공/실패를 가르는 5가지

1. **한 페이지 몰빵 금지** — 1앱 1URL이 절대 원칙.
2. **설명 콘텐츠 필수** — 도구만 있으면 애드센스 거절 + SEO 실패.
3. **유료 트래픽 아비트라지 금지** — 손실 + 계정 정지.
4. **내부 링크로 세션 PV 극대화** — 수익에 직결.
5. **인내** — SEO는 6~12개월. 이 기간을 버티면 비용≈0라 이후 전부 순수익.

## 결론

- "비용의 3배"는 **유료 트래픽을 사면 오히려 불가능**, **무료 검색 트래픽이면 자동 초과 달성**.
- 진짜 목표는 3배가 아니라 **월 PV를 100개 앱으로 키우는 것** → 비용이 0이라 늘어나는 PV가 곧 순수익.
- 실행 순서: **제작(1앱1URL+설명) → 배포(무료 호스팅) → 애드센스 → SEO → 내부링크 → 프리미엄 광고망.**
