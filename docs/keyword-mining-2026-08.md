## 1. 제일 중요한 발견 3개

### ① 졸업식이 리뷰의 5분의 1이다 — 그런데 "누구의" 졸업식인지가 상품명에 없다

`졸업` 언급 **1,275건 (전체의 21.8%)**, `졸업식` 단독으로도 1,069건. 압도적 1위 상황이고
1·2·12월에 집중된다(계절성 뚜렷). 여기까진 이미 알던 사실이다.

**새로 나온 건**: `아들`(208건)·`딸`(185건)이 노출 검색 키워드도구·상품명 어디에도
없다. 그런데 리뷰 본문에서 압도적으로 많이 쓰는 말이다. 실제 co-occurrence:

| 조합 | 건수 |
|---|---:|
| 아들 + 졸업식 | **137** |
| 딸 + 졸업식 | **96** |
| 조카 + 졸업식 | 25 |
| 중학교 + 졸업 | 16 |
| 초등학교 + 졸업 | 13 |
| 유치원 + 졸업 | 11 |
| 대학(교) + 졸업 | 11 |
| 고등학교 + 졸업 | 6 |

> "중학생아들 졸업식에 잘 썼어요" / "초딩딸 졸업식때 쓸려고 몰래 숨겨놨어요" /
> "작은조카 졸업식이라 주문했어요" — 학교급까지 구체적으로 말한다.

`techa-products.json`엔 `유치원·초등학교 졸업·입학`만 occasion 태그로 있고, 중학교·
고등학교·대학교는 없다. 실제로 리뷰엔 이 위 학교급이 다 나온다.
→ **"아들 졸업식 꽃다발" "중학교 졸업식 꽃다발" 류가 통째로 비어 있는 후보군.**

### ② "입학식"은 "졸업"과 다른 검색어다

상품명·occasion 태그는 `졸업·입학`으로 항상 붙여서 관리하지만, 리뷰에서 `입학식`을
**단독으로** 쓴 경우가 25건 있고 문맥이 명확히 다르다.

> "가장 큰 장점은 두번 사용이 가능하다는~ 졸업 후 입학식에도 잘~" — **재사용 앵글**:
> 안 시드니까 졸업식에 썼던 꽃을 입학식에도 다시 쓴다는 얘기. 이건 테차 소재
> 특성(프리저브드=안 시듦)이 만드는 진짜 차별점이라 광고 카피·원고 소재로도 쓸 만하다.

"졸업"과 "입학"을 동시 언급한 리뷰가 21건 — 완전 별개는 아니지만, `입학식`만 따로
검색하는 수요가 있다면 상품명에 "졸업"만 있고 "입학식"이 없는 상품은 그 검색에서
안 보일 수 있다.

### ③ 향기(853건)는 브랜드가 이미 말하지만, "생화 대신"이라는 프레이밍은 안 쓰고 있다

- `향기` 언급 853건, `생화` 언급 507건 — 둘 다 최상위권 명사인데 `already_in_techa_data`
  판정상 "향"은 상품 특성에 이미 있지만 **검색용 문구로 조합된 형태**(예: "향나는
  꽃다발", "은은한 향 프리저브드")는 상품명에 없다.
- `생화` 언급은 대부분 **비교 문맥**이다: "생화보다 예뻐요" "생화보다 오래가요"
  "생화 대신 샀어요" 계열. `생화 + 졸업식` co-occurrence만 125건.
  → **"생화 대신 꽃다발" "생화보다 오래가는 꽃다발"** 류는 리뷰가 실제로 쓰는 비교
  프레임을 그대로 가져온 후보다.

### ⚠️ 참고: 공급자 언어와 고객 언어가 다르다

`전국택배` `무향` `저자극` `납골당` `추모` — 테차가 내부적으로 강조하는 차별점
표현인데 **5,861건 리뷰 어디에도 0건**이다. 반면 `당일`(22)·`다음날`(32) 같은
체감 표현은 실제로 쓴다. 즉 "전국 배송 가능"은 우리가 설명하는 방식이지, 고객이
검색하거나 후기에 쓰는 말이 아니다 — 이 단어들을 상품명 키워드로 밀어붙이는 건
근거가 약하다. 상세페이지 설명 문구로는 써도 되지만 **검색 키워드 후보에서는 빼는 게
맞다.**

(`성묘` 5건 — `docs/archive/keyword-landscape-2026-08.md`가 지적한 추모·납골당 시장과 같은
결이지만, 여기서도 볼륨이 작다. 브랜드 톤 판단 영역이라 여기서는 사실만 적는다.)

## 5. 후보 키워드 리스트 — 네이버 키워드도구 검증 대상

리뷰 근거 강도로 3단계 나눴다. **A부터 순서대로 키워드도구에 넣어라.**

### Tier A — 리뷰 근거 강함 (co-occurrence 10건 이상)

```
아들 졸업식 꽃다발
딸 졸업식 꽃다발
중학교 졸업식 꽃다발
초등학교 졸업식 꽃다발
유치원 졸업식 꽃다발
대학교 졸업식 꽃다발
조카 졸업식 선물
입학식 꽃다발
사장님 개업 축하 꽃
생화 대신 꽃다발
생화보다 오래가는 꽃다발
향기나는 프리저브드 꽃다발
졸업 입학 겸용 꽃다발
```

### Tier B — 근거는 있으나 볼륨 작음 (co-occurrence 2~9건, 검증 필요)

```
고등학교 졸업식 꽃다발
시어머니 칠순 선물
엄마 칠순 선물
와이프 결혼기념일 선물
여자친구 프로포즈 꽃
부모님 환갑 꽃다발
부모님 결혼기념일 선물
아빠 칠순 선물
```

### Tier C — 탐색적 (건수는 낮지만 상품 라인과 정합, 롱테일 후보)

```
담임선생님 선물
손녀 선물
조카 선물 추천
와이프 프로포즈 꽃
남자친구 기념일 선물
```

**주의**: 이 리스트는 "리뷰에 이 말이 있다"는 근거일 뿐, 검색량·경쟁도는 아직 모른다.
`docs/archive/keyword-landscape-2026-08.md`가 이미 경고했듯 **스크래퍼 대신 네이버 검색광고
키워드도구로 직접 확인**해야 한다. Tier A라도 검색량 0이면 버리고, Tier C라도
검색량+낮은 경쟁이면 올라간다.
