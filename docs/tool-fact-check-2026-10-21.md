# 테차 일상 도구 점검 기록

확인일: 2026-10-21. 대상: `/ko/`의 24개 도구. 정적 페이지 구조를 유지하고 계산 로직·설명·예시·문장을 점검했다. 외부 자료는 아래 기관 원문을 검색·열람해 대조했고, 공식 안내에 과거 기준과 현재 기준이 함께 있는 경우 적용 시점을 구분했다. 관습·놀이 콘텐츠에는 검증된 예측 효과가 있다는 표현을 사용하지 않았다.

## 주요 수정

- 부가세: 숙박업 부가가치율 20% → 25%. 제조·운송·서비스 업종 구분 수정. 2026년 4월·10월 신고기한을 주말 다음 영업일로 수정. 고지 전 자진 납부에 고지 후 체납 방식(3% + 월 0.67%)을 일괄 적용하던 오류를 일 0.022%로 수정. 무신고 감면 선택이 실제 계산에 반영되지 않던 오류 수정. 감면을 부정신고·일반 과소신고에 잘못 적용하지 않도록 제한.
- 대출: 금융위원회의 수수료율 **인하 폭**을 현재 수수료율로 오해한 프리셋 제거. 약정 수수료 직접 입력으로 변경. 1,095일 선형 차감 가정 명시. 단순 DSR 비율을 스트레스 DSR 심사 결과처럼 설명하던 문장 수정. 출처·적용 조건이 불명확한 시장금리·정책대출 수치 제거.
- 마진: 실제로 없는 플랫폼 자동 요율 입력 설명 수정. 확인되지 않은 플랫폼 수수료·정산주기 표를 판매자센터 확인 안내로 교체. 상품 차액만 반영하는 부가세 추정의 한계를 명시하고 간이과세와 구분.
- 복리: 월말 적립·월복리·정수 개월 환산 가정 명시. 시행 중인 것으로 단정했던 ISA 확대 수치 제거. 금융소득 종합과세를 단순히 초과분에만 세율을 곱하는 것처럼 설명한 문장 수정.
- 날짜: 1월 31일~3월 1일처럼 월 길이가 다른 경우 음수 일수가 나오는 분해 오류 수정. 월말 보정 방식과 시작일 포함 옵션의 관계 명시. 숙박의 박 수와 여행의 일수 구분. 민법 초일 불산입의 오전 0시 예외 추가.
- 근무일: 2026년 추석 대체공휴일이 있다는 잘못된 FAQ 수정. 지원 범위 밖의 날짜에 공휴일을 제외했다고 표시하지 않고 안내. 20만 일 이상 범위의 조용한 계산 중단 방지. 연차표의 ‘년차’를 계속근로기간으로 명확히 하고 적용 조건 추가. 2028년은 잠정 역자료·현행 규정에 따른 예상임을 표시.
- 로또: 비과세 기준 5만원 → 건별 200만원. 5등 확률과 모든 등수 당첨 확률 구분. 다섯 게임이면 당첨을 기대할 만하다는 문구 제거. 보너스 번호가 구매 선택 번호인 것처럼 보이는 설명과 구매 한도 오기 수정.
- 단위·글자: kB/MB의 10진과 KiB/MiB의 2진을 구분해 모두 지원. 컵·근·계량스푼의 가정 명시. 범용 신발 사이즈 환산표 대신 브랜드별 확인 안내. UTF-8과 EUC-KR 구분, 이모지의 UTF-16 글자 수 기준 명시. TextEncoder로 단독 서로게이트까지 올바르게 바이트 계산.
- 문장·문화: 초등학교 입학 연도 FAQ 모순 수정. 환갑을 ‘예순한 번째 생일’로 표현한 오류 수정. 사수자리·염소자리 등 날짜 범위와 판정 코드 일치. 이름 궁합을 훈민정음의 공식 분류·검증된 근거로 읽히지 않도록 자체 놀이 규칙으로 명시. 꽃말·탄생화·탄생석의 관습과 전설을 구분. 메뉴 후보의 실제 미저장·기본 메뉴 추가 방식과 안내 일치. 사다리의 1:1 연결을 모든 배정의 동일 확률·조작 불가능으로 단정하지 않도록 수정.

## 검증 범위와 한계

계산식은 고정 입력·경계값·기존 회귀 테스트로 검증했다. 법·세금·금융 정보는 개별 심사·신고의 모든 예외를 구현한 것이 아니므로 계산 가정을 본문에 적었다. 미래 공휴일·상품 가격·실시간 금리는 고정 페이지에서 확정 보장하지 않는다. 재미 콘텐츠의 효능·성격 예측과 전설의 역사적 진실은 입증된 사실로 취급하지 않는다.

검증: `node --test tests/tool-facts.test.js tests/dday-occasions.test.js tests/lunar-moon.test.js tests/tool-inputs.test.js`, 공통 구성·관련 도구·상품 영역 생성기 일치 검사, 검색 인덱스 재생성, 브라우저에서 숙박업 25% 선택 및 무신고 50% 감면 결과 확인.
