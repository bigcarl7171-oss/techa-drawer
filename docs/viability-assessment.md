## 2. 그런데 — 이 프로젝트를 살리는 결정적 반증

**핵심: 이건 '콘텐츠(블로그) 프로젝트'가 아니라 '도구(tool) 프로젝트'다. 재앙은 정보성 콘텐츠를 때렸지, 인터랙티브 도구는 오히려 예외다.**

| 방어 요인 | 실증 근거 |
|---|---|
| **도구는 AI Overviews 면역** | "계산기·생성기·설정도구는 텍스트 요약으로 대체 불가. AI가 사용자를 위해 계산을 '대신 해줄' 수 없어 반드시 클릭해야 함 = Click Gap" |
| **프로그래매틱 SEO는 조건부 생존** | "실제 데이터 차별화가 있으면 생존. 각 페이지가 다른 페이지가 답 못하는 고유 쿼리에 답하면 랭크. 제작 방식이 아니라 결과물 품질이 기준" — 진짜 기능하는 도구는 이 조건 충족 |
| **계산기 사이트 2026에도 수익성 존재** | 니치별 RPM: 금융·보험 $15~40, 테크 $8~18, 건강 $6~14, 엔터 $2~6. 미국·영국·캐나다 트래픽은 3~5배 |

➡️ 종합: **우리 140개 앱은 대부분 "진짜 기능하는 인터랙티브 도구" = AI 시대 방어 자산.** 정보성 콘텐츠와 운명이 반대다.

| **AI 내성** | 도구는 제로클릭 면역 | 도구에 딸린 "설명 콘텐츠"는 AIO에 먹힐 수 있음 |

## 4. 기대치 재보정 (확률 가중)

전통적 "월 수백만 원 애드센스" 서사는 2026년엔 비현실적. 냉정한 시나리오:

| 시나리오 | 확률(주관) | 12~18개월 결과 |
|---|---|---|
| 실패(트래픽 못 붙음) | ~40% | 월 몇만 원. 단 **손실은 도메인비뿐** |
| 완만한 성공 | ~45% | 월 수십~수백만 원 부수입(도구 다수 롱테일+한국 니치) |
| 확장 성공 | ~15% | 공용 도구 영어화+1~2개 히트 도구로 월 수백만+↑ |

➡️ **비대칭 베팅**: 하방은 도메인비(연 1.5만 원), 상방은 열려 있음. 비용이 0이라 기대값이 양(+).

## 5. GO의 4가지 필수 조건 (이걸 못 지키면 NO-GO)

1. **도구 우선(tool-first), 콘텐츠 양산 금지.** 얇은 설명글 대량 생산 = 3월 코어 업데이트 표적. 각 앱은 진짜 기능 + 고유 쿼리.
2. **애드센스 단독 금지 → 수익 다변화.** 제휴(affiliate, 도구 RPM의 3~10배)·직접광고·자사 상품(TECHA 꽃/선물—탄생석·꽃말 연계) 결합.
3. **서구 트래픽 경로 확보.** 한국 RPM은 낮다. i18n-ready 구조로 공용 도구 영어화(`i18n-decision.md`) = 수익 3~5배 레버.
4. **6~12개월 인내 + 롱테일 집중.** 대형 키워드 정면승부 금지. KD<20 롱테일·한국 특화(만나이·손없는날·연봉실수령 등 대형사이트가 안 건드리는 것)부터.

## 6. 한 줄 결론

**"수익형 블로그로선 죽은 시장, 하지만 도구 사이트로선 살아있는 틈새다."**
- 2026년 AI·애드센스 붕괴는 **정보성 콘텐츠**를 죽였지, **인터랙티브 도구**는 오히려 몇 안 되는 방어 자산으로 지목됨.
- 비용이 0이라 하방 리스크가 사실상 없고, 실행만 tool-first + 다변화 + 서구확장 + 인내로 하면 기대값은 양(+).
- **판정: 조건부 GO.** 단, "빠르고 큰 애드센스 수익" 기대는 버릴 것. 이건 **저비용·장기·복리형** 프로젝트다.
