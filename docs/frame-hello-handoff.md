## 0. 한 줄 요약

꽃 상자에 넣는 **팸플릿 QR → 안내서(/hello/)** → 선물한 사람·받은 사람이 각각 할 일을 고르고 → **사진 꾸미기(/frame/)**에서 사진·동영상을 고급 틀에 넣어 **사진·영상(MP4)·GIF·카톡 프사**로 만들어 인스타·카톡에 공유합니다. 전부 휴대폰 브라우저 안에서 처리하고 서버·AI·유료 서비스는 쓰지 않습니다.

## 1. 왜 만들었나 (배경 연구 요약)

- 목표: 손님이 **자기 계정에** 테차 꽃 사진을 올리게 만드는 것 (새 손님은 손님 계정 게시물에서 온다).
- 근거로 삼은 연구:
  - 받는 사람을 잘 아는 선물일수록 SNS 공유가 늘고, **고마움·친밀도는 공유를 예측하지 못한다** (Lee & Kang 2023, Asia Marketing Journal, 미국 306명).
  - 브랜드가 보이는 사진을 올리는 이유는 **자기표현·자기 연출**, 그리고 **사진이 예쁜가** (틸뷔르흐대 석사논문 2022, 30명 인터뷰).
  - 돈 보상은 글 수를 늘리지만 글이 짧아지고, 경품 후기는 **광고 표시 의무**가 생긴다 (Burtch 외 2018 / 공정위 추천·보증 안내서 개정 2025-12-02).
  - 인스타 노출 신호: 시청 시간 · 도달 대비 보내기(DM 공유) · 도달 대비 좋아요 (인스타 책임자 애덤 모세리 공개 발언).
- 그래서 원칙: **경품 없음. 손님이 얻는 보상은 '고급스러워진 내 사진'.** 테차의 재게시는 작은 답례일 뿐.

## 2. 누가 쓰나 (가장 중요한 전제)

| 사용자 | 비중 | 상황 | 원하는 것 |
|---|---|---|---|
| **선물할 사람(구매자)** | 팸플릿을 읽는 사람의 **대부분** | 상자를 직접 받아 건넨다. 팸플릿은 이 사람 손에 남고 받는 사람에게 가지 않는다 | 건네기 전 보관법, 카드 문구, **건네는 순간(받는 분 반응) 남기기**, 받는 분께 관리법 전하기 |
| **받은 사람** | 택배로 바로 받았거나, 구매자가 보낸 링크로 들어옴 | 상자를 열었다 | 오래 두는 법, 사진 남기기, 보낸 분께 고맙다고 하기, 카톡 프사 |

## 3. 화면 구성 (현재)

### 3-1. 안내서 `/hello/` (팸플릿 QR: `/hello/?from=leaflet`)
- 맨 위 [선물하실 분] [선물 받으신 분] 선택. 기본은 선물하실 분. 구매자가 공유한 링크(`?to=recipient`)는 받으신 분으로 열림.
- **선물하실 분**: ① 건네는 순간 남기기(찍는 요령 3줄 + 꾸미기 `?mode=giver`) ② 카드 문구(`/message/`) ③ 건네는 날까지 두는 법(소재별 관리법) ④ 받는 분께 안내 공유하기(링크만, 개인정보 없음)
- **선물 받으신 분**: 사진 예쁘게 남기기 · 고맙다고 전하기(`?mode=thanks`) · 카톡 프사 만들기(`?kind=square`) · 오래 두는 법
- 공통: 문제 문의는 **네이버 톡톡 하나**. 맨 아래 공방 소개·의견 보내기.
- 관리법은 `/care/` 페이지의 데이터(JS 객체 `CARE`)를 fetch 후 그대로 읽는다(원본 한 곳 유지).
- **뺀 것**: 한 달 뒤 달력 알림(연락처 없이 휴대폰 달력에 넣는 방식이었으나 이해하기 어렵고 구매자에게 불필요), 전화 문의.

### 3-2. 사진 꾸미기 `/frame/`
**첫 화면**: "테차 꽃을 받으셨나요? / 꽃 사진을 예쁘게 꾸며 드려요" + 완성 예시 3장(누르면 그 틀로 시작) + 3단계 + 개인정보 안심 문구 + 의견 보내기 + 아래 고정 [사진 고르기].

**편집 화면(한 화면에 다 들어오게)**
```
[사진 | 영상 | GIF | 카톡 프사]        ← 만들 형태
        ┌──────────┐
        │  미리보기  │  (영상·GIF면 움직임 재생, 끌어서 사진 위치 조정)
        └──────────┘
[틀] [문구] [사진] [보정]               ← 아래 탭, 편집 시작은 '틀'
 (탭 내용만 안에서 스크롤)
[저장]            [공유하기]            ← 아래 고정
```
- **틀**: 세로 1080×1920 틀 15개(갤러리 액자·박물관 캡션·폴라로이드·매거진 커버·필름·엽서·네 컷·아치 창·골드 라인·편지지·무드등 밤·큰 날짜·다이어리 스크랩·미니멀·변치 않는 날). 카톡 프사는 정사각 틀 3개(꽉 찬 사진·크림 여백·금빛 원).
- **문구**: 사진은 1줄, 영상·GIF는 최대 3줄(차례로 나타남). [어울리는 문구 고르기] → 탭 '추천 문구'(18개 상황 93줄, 받은 사람·선물한 사람 시점) / '카드 문구'(사이트 `/message/`의 228개, 보내는 사람 시점). 영상용 '세 줄 흐름'은 한 번에 세 칸을 채움. 보낸 사람·받은 날.
- **사진**: 최대 8장. 누르면 첫 번째로, ×로 빼기, +로 더하기, 컴퓨터는 끌어다 놓기. 동영상을 넣었으면 [동영상에서 장면 더 고르기] [영상 구간 바꾸기]. 확대 막대.
- **보정**: 필터 7개(원본·자동·화사하게·따뜻하게·차분하게·필름·흑백)를 내 사진 썸네일로. '직접 조정'(밝기·따뜻함)은 접어 둠. 테차 표시 켜기/끄기.
- **동영상 창**: [영상 그대로 넣기] 장면 띠 위 구간을 누르거나 끌어 선택, 3·5·8초, 8초 이하 영상은 전체 / [장면을 사진으로] 자동으로 뽑은 장면 12개를 눌러 고르기(순서 번호), 이미 넣은 장면은 '넣음', 원하는 장면이 없으면 '직접 찾기'.
- **다 만든 뒤 창**: 실제 결과물(영상 재생·GIF·사진)을 보여 주고 [공유하기] [휴대폰에 저장].
- **모드**: `?mode=giver`(선물한 날 문구부터), `?mode=thanks`(고마움 문구·폴라로이드), `?kind=square`, `?tpl=...`, `?recv=YYYY-MM-DD`.
- **보호 장치**: 앱 안 브라우저 감지 시 안내(카톡은 `kakaotalk://web/openExternal`로 사파리·크롬 열기), 휴대폰 뒤로가기는 열린 창부터 닫고 편집 중엔 두 번 눌러야 나감, 8장 초과는 앞의 8장만 넣고 확인 창.

- **정적 사이트**(Cloudflare Workers Assets). 빌드 단계 없음. 의존성은 위 vendor 두 개뿐.
- **렌더링**: `TechaFrame.render(canvas, id, opts, scale)`. 기준 좌표 1080×1920(정사각 1080×1080). 미리보기는 0.5배, 틀 썸네일은 0.25배로 그려 가볍게.
- **인스타 안전영역**(브랜드 규칙): 글자·날짜·로고·도장은 **x 60~950, y 220~1490** 안. 사진·배경은 밖으로 나가도 됨.
- **보정**: 캔버스 `filter` 대신 혼합 모드(screen·multiply·soft-light·saturation·lighten)로 구현 → 아이폰 사파리에서도 같은 결과.
- **영상(사진으로 만드는 6초)**: WebCodecs `VideoEncoder`(H.264) → mp4-muxer(faststart) → 표준 MP4 720×1280 30fps. 안 되면 MediaRecorder 녹화.
- **영상(찍은 동영상 넣기, 최대 8초)**: 동영상을 실제 속도로 재생하며 장면마다 인코딩 + 소리는 `decodeAudioData` → `AudioEncoder`(AAC) → MP4. 안 되면 MediaRecorder(화면+소리 녹화, 소리 길은 버튼 누를 때 열어 둠), 그것도 안 되면 소리 없이.
- **GIF**: 432×768, 초당 10장, 4초 반복, 여러 장면에서 뽑은 **한 팔레트**(깜빡임 방지), 미세 질감 제외(용량).
- **글꼴**: 고운바탕·프리텐다드·나눔펜·Cormorant(전부 OFL). 한글 웹글꼴은 글자 묶음별이라 **그릴 글자를 미리 불러온 뒤** 그린다.
- **기록**: GA4(`G-SEQ155EHQ7`) 이벤트만 — 사진·문구는 보내지 않음. `frame_view/save/share/inapp/feedback`, `hello_view/click/care/who`.
- 시험 결과(헤드리스 크롬): 사진 0.3~0.5MB, 영상 6초 약 4MB(2~4초 소요), 찍은 영상 8초+소리 약 5MB(약 15초 소요), GIF 3~4MB.
